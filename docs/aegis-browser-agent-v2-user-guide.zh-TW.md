# Aegis Browser Agent v2 使用者指南

## 最簡單的用法

1. 點擊瀏覽器工具列或主選單裡的「Agent」。Android 可從新分頁或主選單進入。
2. 直接說想要的結果，例如「幫我摘要這個頁面」、「去京東找三款 32GB 記憶體並比較」
   或「整理書籤並檢查失效連結」。不需要先開啟網頁，也不需要選擇工作流程。
3. 點擊「開始任務」。Aegis 會依序理解目標、制定計畫、開啟或搜尋網頁、執行操作並驗證
   結果。側邊欄會用一般文字顯示目前進度。
4. 只有購買、送出表單、修改大量資料等有風險的動作才會停下來要求確認；最終購買永遠由
   使用者親自完成。

如果已經開啟網頁，「摘要目前頁面」或「比較這幾個分頁」會自動使用目前分頁；如果任務
點名京東、GitHub、Amazon 等網站，Aegis 會直接開啟該網站，不會先把整句話丟給一般搜尋
引擎。

## 桌面無痕模式

- 桌面主要無痕 Profile 透過與一般 Profile 隔離的服務提供 Agent、目前頁面摘要、工具列入口
  和 `chrome://aegis` 控制介面。
- 任務、模型憑據、自動化狀態和隱私事件只保存在該無痕工作階段的記憶體中，不會複製到
  一般 Profile，也無法在無痕工作階段結束後復原。
- 雲端模型 API key 必須在無痕工作階段中另外提供，既不會從一般 Profile 讀取，也不會寫入
  一般 Profile。
- 使用者明確核准的書籤修改和已完成下載遵循 Chromium 原生無痕語意，關閉視窗後仍可能
  保留。關閉無痕工作階段會取消仍在進行的 Agent 下載和 BT 傳輸，但保留已經寫入的 BT
  位元組。BT 任務只在同一 Profile 工作階段內跨設定頁重新整理保留，完成後會釋放，且
  不能控制其他 Profile。
- 處理程序層級 CDP 無法依 Profile 隔離可見目標，因此開啟任一主要無痕工作階段都會停止
  並阻斷整個處理程序的所有 HTTP 與 pipe「AI 控制」傳輸，包括並非由 Aegis 啟動的傳輸。
  無痕關閉後仍維持關閉，必須在一般 Profile 中明確重新啟用。原生 Browser Agent 仍可使用。
- 無痕 Actor 診斷會隱藏私密 URL、頁面/任務資料、目標和憑據識別碼；登入品質記錄不會
  上傳，無痕監控也不會傳送系統通知。
- Guest、System 和輔助 OTR Profile 不會收到 Aegis 介面、服務、網路過濾或指紋保護。
  已學習的 CNAME 別名依精確 Profile 分區，並隨工作階段清除。

## 常用場景

首頁按鈕只是快速填入任務，所有場景也都能直接用自然語言提出：

- 頁面助手：摘要目前頁面、解釋重點、擷取表格或連結、比較多個分頁。
- 商品研究：依預算和條件在指定網站找商品，比較價格、規格、配送和退貨資訊。
- 書籤管家：分類、去重、預覽重新命名，並檢查明確失效的 URL；套用修改前會確認。
- 官方下載：尋找官方來源，核對平台、架構、版本和雜湊，再交給瀏覽器下載中心。
- 安全檢查：解釋隱私攔截或網路釣魚警告，並檢查頁面來源；不會因網頁文字擴大權限。
- 排程自動化：定期檢查價格、庫存、網頁變化、下載版本或書籤連結狀態。

## 排程自動化

「自動化」是獨立入口，不藏在進階設定裡。選擇任務範本後，可設定每 15 分鐘、每小時、
每 6 小時、每天或每週執行。排程會持久保存，但只在瀏覽器可執行且授權仍有效時運作；
需要使用者確認的動作會暫停並通知，不會在背景代替使用者購買、付款或送出敏感資訊。

## 你會看到的流程

- 正在理解：辨識目標、指定網站、目前頁面和風險邊界。
- 計畫已準備：模型給出下一步瀏覽器工具呼叫；格式有輕微錯誤時，Aegis 只自動修復一次。
- 正在執行：依計畫開啟網頁、觀察頁面並執行低風險操作。
- 正在驗證：重新觀察結果，避免把「點過按鈕」誤當成「任務完成」。
- 已完成或需要你處理：顯示結果、來源和下一步；不會只給模糊錯誤碼。

如果模型連續兩次沒有給出可執行格式，Aegis 只會為頁面摘要等 R0 唯讀任務使用最小安全
復原計畫。書籤修改、下載、購物和送出動作不會繞過模型或確認門禁。

## 模型設定

Provider、Base URL 和模型名稱都可由使用者自訂。使用本機 OpenAI 相容服務時，可填寫類似
`http://127.0.0.1:8000/v1` 的位址；loopback 服務可以不填 API key。一般 Profile 的金鑰
由系統安全儲存，無痕金鑰只存在於工作階段記憶體；兩者都不會寫進儲存庫、一般日誌、
任務時間軸或建置產物。

## 出錯時怎麼辦

1. 看紅色提示中的「發生了什麼」和「可以怎麼做」，不要只看技術詳情。
2. 模型未連線時，開啟模型設定檢查服務位址和模型名稱，然後點「重新連線」。
3. 頁面已關閉或發生跳轉時，選擇「重新觀察並繼續」；不要手動複製整段任務去搜尋。
4. 網站要求登入、驗證碼或最終確認時，依提示接管頁面，完成後點「我已完成」。
5. 仍無法繼續時可安全停止；Aegis 會釋放受控分頁，不會在背景繼續點擊。

## 安全和目前平台邊界

- 頁面文字、彈出視窗和下載內容都被視為不可信網頁資料，不能取代使用者指令。
- 401、403、429 和逾時不會被直接判為失效連結；404、410 等明確結果才會列為候選。
- 價格、頁面或權限範圍變化會使舊確認失效，Aegis 必須重新觀察。
- 本輪產品驗收涵蓋 macOS、Android 和 Windows；iOS 明確後置，不屬於 v2 本輪完成範圍。
- 目前候選用於獨立 Profile、公開唯讀網站和本機 fixture 驗收；公開發行、簽署和商店上架是
  獨立門禁。
