# 账号驱动的网站连接服务：首版需求与协作清单

状态：讨论稿；产品目标和当前界面实现分开验收。日期：2026-11-16。

## 1. 需求来源与目标

来源是 2026-11-14 的讨论截图，以及后续“账号拿节点、显示上下行和总用量”的补充。截图中的管理地址和凭据不属于产品需求，不进入本文或客户端。

目标：用户通过自己的账号获取服务权益，开启网站级的“隐藏地理位置”；服务端负责授权、计量和可用连接分配，运维负责多节点供给。用户不需要购买、导入或管理节点配置。

| 来源 | 已表达的要求 | 解释边界 |
| --- | --- | --- |
| 老板 | 用户文案避免“代理”，使用“隐藏地理位置” | 指网站根据出口 IP 推断的位置；不宣称隐藏 GPS、绝对匿名或全设备保护 |
| 老板 | 不必展示截图里的技术细节 | 主界面不展示节点、协议、地址、凭据、配置导入导出 |
| Quinn 的方案 | 账号、支付、多节点由后端服务管理 | 是待落地的服务方案，不能视为支付渠道、套餐和接口已经确定 |
| 老板 | 网站打不开或部分 CF/CDN 拦截时给出使用入口 | 定向建议、用户主动触发；不等于所有错误自动开启或保证绕过网站限制 |
| 本次补充 | 展示上下行和总用量 | 首版建议累计上传、累计下载、累计已用；不默认理解为实时速率 |
| 讨论提议 | Linn、Tom 可协助提供服务器节点 | 属于人员建议，尚无确认的负责人、资源数或交付日期 |

## 2. 首版范围

### 面向用户的正式首版

1. 登录/退出；登录态和设备会话由服务端管理，客户端安全保存短期会话。
2. 查询套餐、有效期、周期额度、上传、下载、已用和剩余；明确数据更新时间和陈旧状态。
3. 购买一个已确认的首版套餐方案；支付结果经服务端验证后生效，重复回调不重复发放权益。
4. 首次打开公网网站时，有可用服务才默认开启“隐藏地理位置”。没有服务配置时直接按原连接浏览，自动准备失败时继续原请求。用户点地址栏内的位置图标即可切换，当前网站面板同步显示选择和连接状态。普通窗口记住手动关闭的域名，私密窗口单独维护会话内选择。本机及局域网站点默认沿用原连接。开启意图不等于已连接，更不等于目标网站已加载成功。
5. 服务端按权益和健康状态分配可用连接；至少支持多个节点，以及新连接的故障切换。首版不承诺现有连接无感迁移。
6. 有服务且可安全重试时，加载失败页提供“隐藏位置并重试”。无服务时保留普通重试。
7. 对确认可识别的 CDN 拦截场景提供提示；单独列出可识别样本、排除项和灰度开关，未完成时不能把普通网络失败提示算作该项验收。
8. 私密浏览遵守既有隔离：不自动展示普通账号用量或复用普通授权；私密会话结束撤销临时授权。

### 这次先落地的客户端界面

- 网站名称：公网网站显示域名，回环地址显示“本机页面”，局域网地址显示“局域网网站”。点击浏览器地址栏仍可查看和编辑实际网址。
- 当前网站：收起技术信息，改为“隐藏地理位置”、实际连接状态、简短作用范围说明；高级连接选项保留已有行为。
- 加载失败：使用清晰的用户动作，错误详情折叠；保留失败目标、导航代次和可安全重试判断。
- 设置 → 隐私保护 → 隐藏地理位置服务：集中查看账号、累计上传、下载和总用量。当前网站只保留本站控制。
- 测试通道现有共享额度明确标注“测试服务用量（共享）”，不包装成个人套餐。没有服务端登录/支付能力时不提供假的登录成功、购买或续费按钮。
- 本次不引入新的支付渠道、节点控制面、流量结算系统或泛化 CDN 检测器。这些是正式首版的协作交付项，不因 UI 完成而关闭。

### 首版暂不包含

手动选节点、节点配置导入导出、全设备 VPN、复杂地区选择、优惠券/邀请返佣、多币种、多层级订阅组合、实时速率图、自动重放 POST、对所有网站拦截的通用处理、历史账单分析。是否需要地区选择、退款和跨平台权益另行确认；必需的渠道退款通知仍须正确撤销权益。

## 3. 客户端、服务端、节点运维工作拆分

| 编号 / 归属 | 工作与交付物 | 依赖 / 验收责任 |
| --- | --- | --- |
| C1 客户端 | 三个用户界面、动态字体、深浅色、辅助功能、错误和空状态、多语言 | 设计口径；客户端负责人 |
| C2 客户端 | 登录态、退出、设备撤销；普通与私密授权生命周期 | S1；客户端与后端联合 |
| C3 客户端 | 获取/续期/撤销连接授权；网站及其页面资源、下载的路由范围一致 | S3、N2；联合端到端验收 |
| C4 客户端 | 服务端累计用量展示、刷新、离线/陈旧状态；不在本地决定计费结果 | S4；客户端与后端 |
| C5 客户端 | 安全重试提示、失效动作取消、防重复提交；CDN 样本识别和提示频控 | 服务能力就绪；客户端 |
| S1 服务端 | 账号、会话、设备管理、权限校验、撤销和审计 | 登录方式、设备限制待定；后端 |
| S2 服务端 | 套餐、订单、渠道验签、幂等支付通知、权益发放与撤销 | 支付渠道和商业规则待定；后端 |
| S3 服务端 | 权益鉴权、健康节点选择、短期连接凭据、续期/吊销、并发限制 | N1/N2、设备规则；后端 |
| S4 服务端 | 每账号/周期的权威用量账本、上传下载汇总、节点上报去重、跨节点一致性、耗尽停流 | 计量和重置规则；后端与运维 |
| S5 服务端 | 管理台：账号、套餐、订单、节点、用量、停用、操作审计；分权访问 | 管理员角色待定；后端 |
| N1 节点运维 | 节点部署模板、接入登记、区域/容量、证书与密钥轮换、版本和回滚 | 服务端注册契约；运维 |
| N2 节点运维 | 连接鉴权、计量、停流、凭据撤销、上报重试/去重、隔离测试 | S3/S4；运维与后端 |
| N3 节点运维 | 健康探测、容量告警、排空和下线、故障演练、日志脱敏与留存 | 监控及响应责任待定；运维 |
| J1 联合 | 测试环境、固定测试账号、跨两节点/两设备验收脚本、故障注入、版本绑定报告 | 三方负责人确认 |

负责人和时间由会议填写，不预设已承诺分工。客户端可以先做 C1；C2–C4 的生产验收依赖真实服务接口，不能靠假数据关闭。

## 4. 建议的交互与数据契约

主路径：登录 → 查看权益/购买 → 服务端确认生效 → 开启当前网站 → 取得短期连接授权 → 建连 → 节点计量并汇总 → 展示账号用量。

| 能力 | 最小字段/语义（建议，不是已签字的接口） |
| --- | --- |
| 登录会话 | accountId、sessionId、过期时间、刷新/撤销方式；客户端不持有节点管理密钥 |
| 权益查询 | 服务端状态、planId、periodId、周期起止、expiresAt、quotaBytes、uploadedBytes、downloadedBytes、usedBytes、remainingBytes、measuredAt、服务器时间和数据新鲜度 |
| 订单 | 不可变套餐快照、订单号、支付状态；异步处理中不能显示已开通；回调必须验签、去重、校验金额与商品 |
| 连接授权 | 绑定账号/会话/周期/浏览上下文的短期凭据、过期时间、可续期状态；不返回管理凭据 |
| 用量上报 | 节点身份、账号/授权、周期、单调序列或唯一事件、上传/下载字节；乱序、重复、重启不得重复扣量 |
| 错误 | 未登录、无权益、过期、耗尽、设备受限、服务不可用分别可判定；允许重试与否、重试间隔 |

用量约定建议：上下行按用户视角；`used = uploaded + downloaded`，`remaining = max(quota - used, 0)`；以服务端账本为准。字节计数使用十进制整数字符串，避免跨语言大整数精度丢失。展示单位当前为 KiB/MiB/GiB，商业套餐 GB 口径需要确认并明确标注。没有数据用“—”/不可用，不能展示为 0。周期统计不能混入本次连接流量；服务端测量时间不能用客户端查询时间代替。

“不暴露节点”首版建议指 UI 无节点地址、协议、凭据、导出入口。客户端为了建连仍可能接触入口地址；若要求抓包也无法获得真实后端节点地址，需要网关/中继架构、成本和故障边界设计，不能通过隐藏一行文字实现。

## 5. 验收标准

| 编号 | 场景与通过条件 | 主责 |
| --- | --- | --- |
| A01 | 未登录、加载中、无套餐、有效、过期、耗尽、查询失败均有真实状态；失败不变成零余额 | C/S |
| A02 | 相同支付事件重复发送只生效一次；伪造、金额/商品不符、串账号被拒绝；成功前 UI 不提前开通 | S |
| A03 | 同账号两设备、两节点产生已知上下行流量；汇总与约定计量口径一致；重复上报不重复累计；周期切换不串账 | S/N |
| A04 | 无权益、到期、撤销和耗尽由服务端/节点阻断；绕开客户端 UI 不能继续使用；停流延迟和最大超额需先确定数值再验收 | S/N |
| A05 | 有可用服务时首次公网导航走服务连接，图标显示开启；缺少配置或自动准备失败时用原连接，图标显示关闭。用户明确开启或已绑定的连接故障时不静默直连。点图标可切换，普通窗口重启保留关闭选择，其他网站和私密会话独立 | C |
| A06 | 失败提示绑定实际失败网站；仅安全 GET/HEAD 可重试；POST、带请求体或授权头、TLS 错误、过期导航不重放；同动作不重复发送 | C |
| A07 | CDN 识别只匹配批准样本；正常页面、验证码、登录页和无关 403 不误报；用户拒绝后遵守频控；不保证一定可访问 | C |
| A08 | 普通/私密会话隔离；私密页不展示普通账号额度；退出和关闭私密会话撤销所属授权，不影响其他授权范围 | C/S |
| A09 | 下线一个节点后，新授权避开故障节点；活动连接行为与约定一致；无可用节点时有明确失败状态 | S/N |
| A10 | 默认用户界面无节点 ID、协议、地址、令牌；仅展示网站和必要服务状态。诊断导出必须脱敏 | C/N |
| A11 | 用量页可见总已用、总额度、剩余及累计上下行；更新时间与测量时间区分；离线/陈旧不冒充实时 | C/S |
| A12 | iPhone/iPad、浅深色、最大动态字体、VoiceOver、至少中英文流程可用；14 语言资源完整，母语校对单列 | C |

证据应绑定最终提交和测试环境。源码检查、单测、模拟器、真机、CI、签名/商店和发布各自记录；其中一项通过不能替代其他项。CDN、支付、跨节点计费未联调属于未验收，不记作 UI 已覆盖。

## 6. 待确认事项（会议逐项决定）

| 优先级 | 决策 | 建议起点 / 影响 |
| --- | --- | --- |
| P0 | 登录方式与现有账号体系是否复用 | 先确定唯一账号主体，避免额度查询账号与网站连接身份分离 |
| P0 | 首发平台、支付渠道、恢复购买/退款规则 | 确定真实渠道后再定订单协议；不能以 sandbox 订单代替正式支付 |
| P0 | 套餐、周期、时区、额度单位、到期/耗尽行为 | 首版少量固定套餐；重置/结转/退款规则必须明确 |
| P0 | “不暴露节点”是 UI 隐藏还是网络层源站隐藏 | 后者需要网关设计和预算 |
| P0 | 账号最大设备/并发、跨节点计量误差与停流时限 | 需要明确数值，不能用“及时”“准确”代替验收 |
| P0 | 网站范围：第三方资源、跳转登录页、下载是否同一权益 | 建议同一授权体系；不默认扩展到设备其他应用 |
| P1 | 独立的“本站打不开时自动重试”选项默认值及保留周期 | 保留现有用户选择；新用户是否默认开启需产品确认 |
| P1 | CDN 拦截首批样本与频控 | 先选可验证样本，不对所有 Cloudflare 页面统一提示 |
| P1 | 共享测试节点何时退出用户通道 | 切换时检查旧配置、旧授权撤销与个人账本迁移 |
| P1 | 是否允许地区选择、是否需要本次实时速率 | 首版建议自动选择、只显示周期累计量 |
| P1 | 三方负责人、测试环境、告警值班、交付日期 | Linn/Tom 仅是讨论建议，需明确认领 |

建议交付顺序：界面和契约 → 账号/权益查询联调 → 连接授权与节点计量 → 支付与套餐 → 多节点故障演练 → CDN 定向提示 → 联合首版验收。
