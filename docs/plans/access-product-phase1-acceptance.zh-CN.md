# Access「产品阶段一」验收清单

日期：2026-11-08（Asia/Shanghai）  
期望一句话：用户点一下 allow / block（或等价「本站代理」开关），被墙站点可访问；关闭后回到原有连接，且不静默直连。

相对对象：

| 维度 | 含义 | 当前状态（约） |
| --- | --- | --- |
| **工程小闭环** | F1–F11 + SOCKS5 无认证（iOS/macOS）管道与合同 | fork `develop` 已合入；上游 #97 仅手递不合 |
| **产品阶段一** | 可信入口 + 真实节点 + 五步可演示链路 | **未达成** |

本清单只验收产品阶段一；不把单元测试绿、CI 绿或管道类型存在写成 PASS。

## A. iOS 产品阶段一

平台：Aegis iOS（AccessKit + WebKit 数据面）。工程小闭环已有：合同、HTTP/HTTPS 入站、SOCKS5 无认证、Reality 出站/运行时/探测、HTTP→Reality 汇合、ProxyConfiguration 接线。

### A1. 入口与文案

| ID | 项 | 通过条件 | 相对工程小闭环 |
| --- | --- | --- | --- |
| A1-1 | 本站开关入口 | 当前页有可信「使用本服务代理 / 关闭」控件（气泡或等价） | **缺**：仅有 AccessKit API，无产品开关 |
| A1-2 | DEV ALLOW/BLOCK | DEV 可对明确目标 ALLOW（代理）或 BLOCK（本地拒绝） | **缺** |
| A1-3 | 开关 ≠ 连通 | 「已开启」与「连接可用」分开展示 | **缺** |
| A1-4 | 文案 | 关闭=「未使用本服务代理 / 使用浏览器原有连接」；不写「已直连成功」除非核验 | **缺** |

### A2. 五步主链路（必须全部 PASS）

| ID | 步骤 | 通过条件 | 相对工程小闭环 |
| --- | --- | --- | --- |
| A2-1 | 开启 | 从可信入口提交本站代理；后台完成配置/运行时准备；UI 到「已生效」或可读失败原因 | 有 F8/F9/F11 类型；**无入口与 finalize 产品路径** |
| A2-2 | 指定出口加载 | 对被墙/受控站点导航成功；流量经 Reality 出口到达目标（关联日志证明） | F11 可拨号缝；**无真实节点端到端证据** |
| A2-3 | 故障不直连 | 节点故障或停代理后，新请求失败或等待；**不得**静默 DIRECT 打开目标 | 合同有 fail-closed；**未做产品故障演练** |
| A2-4 | 恢复 | 节点恢复后再次开启/自动恢复可访问；不重放脏会话冒充成功 | **缺** |
| A2-5 | 关闭回原生 | 关闭后新请求走原有连接设置；无本服务代理残留 | F9 可清配置；**无产品关闭验收** |

### A3. 范围与隔离

| ID | 项 | 通过条件 | 相对工程小闭环 |
| --- | --- | --- | --- |
| A3-1 | 当前网站范围 | 仅精确 host（及合同内同域协议组）；CDN/登录子域不自动带上 | 合同有；**缺 UI 范围说明与用例** |
| A3-2 | 标准/私密隔离 | 私密 Profile 开关与标准互不泄漏（F13 产品语义） | **未做 F13** |
| A3-3 | HTTPS 站点 | HTTPS 本站可走 Reality（F12 产品路径） | 有 HTTPS 入站壳；**无 HTTPS→Reality 汇合产品验收** |
| A3-4 | 防护不解除 | 开启代理不绕过钓鱼/安全拦截 | 合同有；**缺联合用例** |

### A4. 证据门（iOS）

| ID | 项 | 通过条件 |
| --- | --- | --- |
| A4-1 | 同候选五步包 | 同一 build/SHA 下：操作记录 + 日志关联 ID + 至少开/关各一张界面证据 |
| A4-2 | 模拟器 | 允许 Simulator 记 `SIMULATOR_PASS`；真机/TestFlight 另列，不 internally 升级为发行门 |
| A4-3 | 禁止拼证 | 不得用不同 SHA 的单测/CI 绿拼成产品 PASS |

**iOS 产品阶段一退出标准：** A1 全部 + A2 五步全部 + A3-1/A3-4 + A4 证据齐。A3-2/A3-3 可作为同阶段加项或紧随切片，但未做不得宣称「整站 HTTPS/私密完成」。

## B. macOS 产品阶段一

平台：Aegis macOS Chromium。工程小闭环已有：路由/所有权等历史 overlay + 本轮 SOCKS5 无认证入站；**产品开关与试用五步历史上仍未验收。**

### B1. 入口与文案

| ID | 项 | 通过条件 | 相对工程小闭环 |
| --- | --- | --- | --- |
| B1-1 | 工具栏气泡 | 当前域名 + 本站代理开关 + 短状态 | **缺**（相对本轮晋升） |
| B1-2 | 管理页 | 流量/网络状态/已保存网站开关列表（渠道可见范围按 DEV/Alpha） | **缺** |
| B1-3 | DEV ALLOW/BLOCK | 调试视图可 ALLOW/BLOCK 明确目标 | **缺** |
| B1-4 | 开关 ≠ 连通 | 同 iOS | **缺** |

### B2. 五步主链路（必须全部 PASS）

| ID | 步骤 | 通过条件 | 相对工程小闭环 |
| --- | --- | --- | --- |
| B2-1 | 开启 | 可信入口 → 配对/install/finalize → 已生效或可读失败 | 历史试用目标；**未交付** |
| B2-2 | 指定出口加载 | 页面经指定代理出口到受控/被墙目标；origin 与浏览器日志关联 | **未交付** |
| B2-3 | 故障不直连 | 节点故障后新请求失败；不回落 DIRECT/其他代理 | **未交付** |
| B2-4 | 恢复 | 节点恢复可再访问；Network Service 重启后策略正确重建 | **未交付** |
| B2-5 | 关闭回原生 | OFF 后恢复当前原生连接配置；无旧代理选择残留 | **未交付** |

### B3. 范围与数据面

| ID | 项 | 通过条件 | 相对工程小闭环 |
| --- | --- | --- | --- |
| B3-1 | 请求级路由 | 命中站点规则的导航/子资源走 PROXY；未命中不误伤 | overlay 有规划器；**缺产品联调** |
| B3-2 | HTTP + SOCKS5 入口 | 完整交付两种本机入口可用（实施可先 HTTP） | SOCKS5 无认证已有管道；**缺产品路径** |
| B3-3 | Profile 隔离 | 不同 Profile 开关与会话不串 | 部分基础设施；**缺试用验收** |
| B3-4 | 防护不解除 | 同 iOS | **缺联合用例** |

### B4. 证据门（macOS）

| ID | 项 | 通过条件 |
| --- | --- | --- |
| B4-1 | 同候选五步包 | 同一 Chromium/候选 SHA：运行日志 + 关联 ID + 开/关界面证据 |
| B4-2 | 原生包 | 以实际可启动的 macOS 构建验收；不能只用 overlay 单测 |
| B4-3 | 禁止拼证 | 同 iOS |

**macOS 产品阶段一退出标准：** B1 + B2 五步 + B3-1/B3-4 + B4。B3-2 两种入口齐备前可标 `PARTIAL`（仅 HTTP），但文案须写明 SOCKS5 未产品验收。
