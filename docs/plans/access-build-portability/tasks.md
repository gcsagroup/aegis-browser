# Access 共享核心实施任务

| 任务 | 需求 | 实施和退出条件 |
| --- | --- | --- |
| T0 | R1–R6 | 固定基线、范围、目标架构与证据格式。 |
| T1 | R1–R4 | 落库清单、CMake 目标、预设、向量生成和 CTest。macOS 编译并运行合同，检查向量和清单的增量重建。原脚本继续生成覆盖率。 |
| T2 | R1、R3、R4、R6 | GN 使用同一清单，更新两条补丁序列。分别记录补丁重放、GN 检查、编译和集成用例。 |
| T3 | R2、R3、R6 | Windows 原生运行合同，Android 使用 NDK 构建并在匹配 ABI 的设备或模拟器运行。分别记录编译与执行。 |
| T4–T7 | R4–R6 | 后续实现平台运行接口和 Windows、Android 接入，再验收开启、代理出口、故障不旁路、恢复、关闭和资源回收。 |

提交 PR 前运行当前仓库质量门和独立只读复核。证据未齐的平台保留未完成状态。保留现有的自动 CI 策略及平台手动入口。
