## 唯一近期目标

一个测试 Profile、一个测试账户、一个已授权受控节点：**开启网站代理 → 页面经指定出口成功加载 → 节点故障不直连 → 恢复后再次成功 → 关闭规则后恢复当前原生行为**，随后接同链路真实计量与额度截断。关闭仅影响网站开关拥有的协议组；更具体的独立 PROXY/REJECT 保留并显示限制。浏览器、代理与 origin 的关联证据必须同时存在。

这仍是阶段性工程验证，不降低完整 W1/W2/W3、G0–G3 或 Alpha 条件。修复同时证明成功、安全和恢复可用；永久 fence/Busy、测试专用 guard、局部负例或文档更新不能结项为恢复。
