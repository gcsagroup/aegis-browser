# iOS 可移植功能补齐计划

用户已授权三批实现、集中测试、iPhone/iPad 模拟器实际操作及三语文档更新。基线为 `main` 的 `e96c623`；桌面阅读与签名等已有未提交改动另行保留。本轮不提交正式发行、不更换 App 或构建目录。

## 步骤与验证

1. 浏览设置：搜索引擎及自定义模板、主页、启动恢复、网页缩放、桌面模式、脚本/弹窗/媒体选项、历史开关、按来源隔离的网站权限和数据管理。
   - 验证：搜索参数转义、配置重启回读、网站来源隔离、权限询问、私密保存确认、实际页面缩放和导航行为。
2. 保护与资料：导航保护设置、前台过滤规则自动检查、加密阅读资料库、网页/PDF 文字层批注、检索、归档恢复、翻译预览与主动保存。
   - 验证：更新节流和失败保留、正文来源绑定、敏感内容处理、密文与并发保存、PDF 页码和无文字层、取消发送与重启回读。
3. 浏览器操作与下载：手动或模型建议的有限步骤、范围预览及执行确认、前台网页变化检查、下载网络及容量设置。
   - 验证：跨窗口/模式/导航拒绝、计划过期与重放拒绝、取消与部分完成、后台停止检查、下载请求策略和续传规则、真实文件哈希。
4. 四端清单与文档：macOS、Windows、Android、iOS 使用同一功能标识；每项记录实现差异、源码和验收依据。新增桌面功能没有 iOS 状态时检查失败。
5. 集中验收：固定路径构建 Ver 4.0，递增构建号；双模拟器原生及 UI 回归、实际操作、三语文案与文档链接检查，失败保留并修复复测。

## 范围边界

- 继续使用系统 WebKit，模型建议不能成为任意脚本执行接口；登录、支付和表单提交不自动化。
- 网页变化检查仅在用户明确启动且面板保持前台时运行，停止后不安排后台请求。下载继续使用系统后台会话。
- 私密页面的正文、来源和任务不自动落盘。显式保存/导出时说明持久化范围并再次确认。
- 深层 Chromium/V8 修改、桌面扩展安装、BT/磁力后台服务、跨设备同步均在四端清单中如实记录，不使用无实现的开关。
- 四端清单不把源码存在、模拟器验证或 macOS 验收扩大为 Windows/Android 实机、实机 iOS 或正式发行资格。
