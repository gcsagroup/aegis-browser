# 本机翻译与可选研究模型接入


> 2026-10-13 公开源码说明：以下研究模型实测来自本机专用资产。公开提交保留接口与评测代码，但不附带 MINIM、PhishLang 权重及配套词表；尝试分析时会明确报告模型未附带，不自动下载。

## 目标与范围

本轮按用户要求将真实本机翻译接入现有阅读面板：中英语言包按需下载，下载后离线翻译，逐段原文对照，并复用已有加密资料库保存和搜索。MINIM、PhishLang 在设置中默认关闭，开启后可主动运行本机实验分析。

研究模型上一轮存在严重误删、误报，因此本轮只展示评分，不自动删除正文、拦截网页或改变 Agent 授权。分析对象是阅读面板已提取的段落副本，不是网页全部 HTML 或完整 AX 树。

步骤与验证：

1. 固定引擎、模型及来源摘要 → 检查文件摘要，比较导出模型与原实现。
2. 接入下载、Worker、取消、原文对照与加密保存 → DOM 回归和原生存储测试。
3. 增加实验开关及分析结果 → 验证默认不运行、开启后真实推理、关闭后停止入口。
4. 编译到唯一输出并固定证书签名 → 固定 App 路径、独立验收配置中实测，结束后恢复日常会话。

## 已实现的行为

- 本机翻译不要求 API 密钥，也不依赖隐私 AI 的远端服务开关；网页与有文字层的 PDF 均复用提取副本。
- 英语→简体中文约 36.13 MB，简体中文→英语约 47.60 MB。仅点击下载时，由原生端请求固定的 Mozilla 语言包地址；原生白名单限定七个文件、固定大小、无凭据、禁止重定向和两分钟单文件超时，每个配置最多两个并发请求。Worker 再核对压缩与解压摘要，整套文件完整后才写入缓存。
- 推理只读取本机缓存和随 App 安装的运行时。长段先分块，保持原有段落顺序；译文使用纯文本显示。
- 取消或离开页面会终止 Worker。下载失败、校验失败和存储不足不把半包标为可用。
- 新提取内容先翻译后由用户保存；对已保存资料翻译时，同时保存当前批注。原文不由客户端结果替换，资料库仍检查修改版本，避免覆盖其他窗口的变更。
- 实验开关保存在当前配置中，两个默认值均为关闭。开启开关本身不加载模型，点击“实验分析”才运行；结果不驱动自动操作。
- MINIM 提供文章、邮件、消息、评价四种阅读目标，使用对应训练目标标识；段落被视作同层静态文本节点，明确不宣称复现完整网页裁剪。

## 模型与数值验证

Bergamot Translator 0.4.9 与 Mozilla 中英语言包沿用前一轮已实跑的来源。ONNX Runtime Web 固定为 1.20.1，使用单线程 WASM。没有新增常驻 Python 服务。

PhishLang 原 safetensors 先导出为 ONNX，再对 MatMul/Gemm 做 INT8 量化，模型约 38.85 MB。用上一轮相同的 46 条已观察样本重跑，分类全部一致：29 条钓鱼识别、2 条漏报、14 条正常网页误报、1 条正常网页识别。量化分数不与原浮点分数逐位相同，仍不能把输出当作安全保证。

MINIM 使用上一轮真实训练的 MLP 权重。浏览器实现与 PyTorch 对照的四个样例评分差异小于 `1e-5`；MobileBERT 分词与原实现对照了 12 个样例，包括中文、组合重音、标点、特殊词元及长词。

来源、许可及摘要位于 [NOTICE](../apps/browser/overlay/chrome/browser/resources/aegis_agent/local_ai/NOTICE.txt)、[研究模型清单](../apps/browser/overlay/chrome/browser/resources/aegis_agent/local_ai/research_manifest.json) 和 [资产清单](../apps/browser/overlay/chrome/browser/resources/aegis_agent/local_ai/asset_manifest.json)。研究代码与权重的公开分发许可仍未明确，本轮属于用户要求的本机实验接入，没有公开发布。

## 实机中发现并修复的问题

- 打开语言包设置会刷新资料列表，曾丢失已保存条目中的未提交批注。现在保留编辑副本，并在保存成功后清除；已覆盖刷新、搜索、保存冲突和后续外部更新。
- 已取消 Worker 的排队消息曾可能清理新任务的计时器。现在按任务隔离消息与超时回收，回归通过。
- 164 实机首次下载遇到 Mozilla CDN 无 CORS 响应头。165 改为固定清单的原生下载入口，WebUI 连接策略收紧为仅同源；没有关闭 CORS、证书检查或脚本安全策略。
- 进一步实测发现 CDN 对默认 Chromium 请求标识返回 HTTP 406，而准确的 `GCSA-Aegis-LocalTranslation/1.0` 下载器标识可获取摘要一致的文件。167 使用此标识；166 同时替换了有 5 MiB 上限的字符串下载接口，采用按清单大小限制的流式接收。

- 中英两个方向的实机下载均完成摘要校验。首次推理暴露了运行时兼容问题：Bergamot 环境判断、WebUI 嵌套 Worker 加载和 WASM 胶水的模块严格模式。最终改为单 Worker 内完成推理，使用模块相对路径加载资源，并修复全局对象引用；没有扩大脚本安全策略。170 的真实七文件、双向推理原生浏览器测试通过，耗时约 3 秒。

### 固定 App 实机验收

构建使用唯一输出 `out/AegisRelease`，安装路径为 `/Users/lazy/Applications/GCSA Aegis Test.app`；验收使用独立的 `GCSA Aegis Acceptance` 配置。

1. 英文网页提取、5 段本机翻译、原译对照、引文、批注保存和按批注搜索均通过。样例保留了否定句、12.5 MB、2026 年 10 月 13 日和上午 9:30。
2. 退出后通过仅作用于验收实例的不可连接代理重新启动；访问未缓存地址明确显示 `ERR_PROXY_CONNECTION_FAILED`。此时已保存英文、中文仍可重新翻译，并同时保存修改后的批注。原文、译文和引文在重启后保留。
3. 已保存的 PDF 第 3 页文字在断网时完成翻译，原页码、引文和批注保留。该验收不覆盖扫描件 OCR。
4. 长文 29 段任务主动取消后，界面确认取消且批注保留；重新执行完成至第 28 个正文段落（另含标题），译文和批注保存成功。
5. 设置显示语言包可离线使用，MINIM 和 PhishLang 起始均关闭。断网开启并主动运行两者后得到真实评分：PhishLang 0.6850；MINIM 五段必要性约 0.03、敏感性约 0.01，正文未被修改。验收后关闭两者，重启后界面和配置文件均确认为关闭。
6. 最终重启后，按新批注搜索可找到中英两条资料；按新译文片段搜索可找到中文资料。原日常三个标签已恢复，额外空白窗口已关闭，三个测试 HTTP 服务已停止；日常实例未带验收配置或断网代理参数。

### 已知限制与下一步

- 翻译质量仍需原文对照。短句 “Do not close the window.” 在独立真实模型烟测中误译为“切不着窗户。”；较完整的下载提示句在正式阅读面板中正确。标题译法也不自然。本轮没有手工替换模型输出，不能以流程通过宣称翻译准确率达标。
- PhishLang 已观察样本误报较高；MINIM 是段落副本上的 MLP 实验，并非完整网页裁剪。两者继续默认关闭，只展示评分。
- 公开分发研究代码及权重前仍需明确许可；本轮仅完成本机实验安装，不代表公开发布或公证。
- 下一步优先扩充独立中英质量样本，覆盖否定句、短标题、日期数字和长文，再决定是否更换语言包；研究模型继续做独立误报评估，不自动启用。
