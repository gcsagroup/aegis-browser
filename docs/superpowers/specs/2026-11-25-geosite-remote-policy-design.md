# 网站加速规则与远程配置

本设计适用于支持网站加速的普通浏览。更新周期可选 1、3、7 天，有效值依次取本机选择、有效远程默认和本地默认 3 天。镜像发布另行设计。

## 候选规则与升级

从同一份 XTLS 正式发布的标准 DAT 获取国内三组、海外母集、排除组和用途证明。发布元数据、DAT 和校验文件必须匹配对应 SHA-256。App 发布包固定官方来源及快照版本，通过现有准入与分类约束解析。海外加速首次使用需要显式确认范围，离线可确认内置版本，界面显示来源及版本。

每次创建 iOS 发布包时，GitHub Actions 对内置快照做两项检查。真实性检查按内置 tag 读取 `repos/XTLS/Xray-rules-dat/releases/tags/<tag>`，验证 tag、发布 ID、必填元数据及两份资产的大小和 SHA-256。该 tag 缺失、变为草稿或预发布，或者资产摘要不符时，发包失败。新鲜度检查读取 `releases/latest`，只限制内置版本落后的程度。内置 tag 晚于 latest 时发包失败。latest 的发布时间比内置版本晚 14 天以上时发包失败。落后不超过 14 天时，发包继续并给出警告。14 天是运行时最长更新周期 7 天的两倍。落后程度按上游两次发布的间隔计算，不按当前时间计算，所以上游停止发布不会阻断发包。上游通常每天发布，因此不要求内置快照与 latest 相同，否则同一提交隔天重跑也会失败。归档后，从 `Aegis.app` 读取 GeoSite 和公共后缀表，使用与 App 相同的 Swift 准入逻辑验证国内投影及海外规则。这一步只比对归档与仓库中的元数据，不访问上游。新版快照在切发包提交时更新到仓库，后续上传或推广同一产物复用已归档的版本。初版内置固定到 `20261126014317`，其中 DEBIAN 新增 `debian.map.fastlydns.net`。已有账本的安装和仅有旧版网站加速设置的安装都按原批准边界收窄。

在仓库根目录运行 `python3 -B scripts/release/ios-refresh-geosite.py` 刷新内置快照。命令默认从 XTLS 的 `releases/latest` 选定 tag，也可用 `--tag` 指定正式发布，或用 `--dry-run` 验证候选。命令按 tag 下载并验证 DAT 和配对校验文件，从发布说明与 Git tag 取回两个来源提交，再生成三项资源、Swift 内置版本、编译器来源、当前测试期望和第三方声明。对应的历史测试输入保留各自版本号。

写入前用固定的公共后缀表编译 DEBIAN、DOUBAN 和 MEITUAN。任何一组的类型化规则摘要与当前批准值不同时，刷新停止，变化的范围需要评审。每周一 12:23（新加坡时间），`quinn521/aegis-browser` 的 `develop` 运行同一命令，并验证 Swift 归档资源准入和声明。出现已验证的新版本时，工作流用该 tag 创建待评审的 PR。建 PR 的步骤使用个人仓库现有的 `AEGIS_FORK_AUTOMATION_TOKEN`，凭据需具备该仓库的 Contents 和 Pull requests 写权限。同一 tag 复用已有 PR。若 PR 已关闭且未合并，工作流报错并给出重开入口。刷新进入正常的评审和发布流程，新鲜度按发包准入检查执行。

账本恢复验证历史发布回执、owner、批准范围和撤回记录。当前内置 tag 限制未来网络候选，升级不因历史记录早于内置 tag 而丢弃账本。已撤回范围保持有效。规则到期或被远程封禁时，使用内置规则与仍获授权范围的交集。国内按规则类型与主机取交集。海外复用精确入口、后缀和排除规则交集。回退候选本身也须通过版本封禁检查。已知有收窄但无法证明交集时，保留现有的保守连接处理。内置授权保留原始批准范围和来源版本，升级后用同样的交集裁剪。

海外账本记录批准来自内置版本还是下载版本。升级到新内置版本时，旧内置授权立即裁剪并保存交集。下载批准按下载规则的原始到期时间检查，即使发布回执与内置版本相同。无需恢复旧预览时，可离线确认符合海外规则水位的新版内置规则。

## 检查周期

复用现有前台检查。周期选择、最近成功检查和失败退避状态一起持久化。兼容没有周期字段的账本，未知周期按未选择读取。下次正常检查取最近成功时间加周期与有效下载规则最早到期时间减提前量的较早值。默认提前 24 小时。同一版本靠近到期时，重查间隔取剩余有效期的一半，上限默认 6 小时。304 保留原 DAT 到期时间，到期路径直接重算有效规则。失败按原有 1 分钟、5 分钟、30 分钟、6 小时退避。修改周期重算正常调度，失败退避仍有效。海外条件请求需要已经下载并验证过同版海外快照。海外开启后即使国内为手动模式仍可更新。

## 签名静态 JSON

使用应用构建时提供的固定 HTTPS URL 和独立 Ed25519 公钥。部署可使用单个静态 JSON 文件。外层包含 Base64 原始 payload 和 64 字节签名，验签覆盖原始 payload。发送固定 User-Agent，请求独立于浏览器存储和账户，使用无 Cookie 的临时会话。远程配置允许在规则有更新资格或仍有远程限制时检查，成功后隔 24 小时，失败后隔 5 分钟。海外暂停时仍可接收解禁。生产地址和公钥由持有服务与签名密钥的发布方提供。

发布方可将签名后的静态文件放在公开 GitHub 仓库的固定分支路径，通过 `raw.githubusercontent.com` 获取，或从 GitHub Pages 提供。iOS Delivery 读取同名仓库变量 `AEGIS_GEOSITE_POLICY_URL` 和 `AEGIS_GEOSITE_POLICY_PUBLIC_KEY`，后者为 32 字节 Ed25519 原始公钥的 Base64。签名私钥由发布方保管。使用 `node scripts/dev/sign-geosite-policy.mjs 3<private-key.pem <payload.json >policy.json` 从文件描述符 3 读取私钥，从标准输入读取 JSON，再将生成的文件发布到已配置的 URL。

签名 payload 使用 `schema: 1`、正整数 `version`、Unix 秒 `issuedAt` 和 `expiresAt`。可选调度字段为 `defaultRefreshDays`（1、3、7）、`expiryLeadHours`（6 至 72）、`lateRetryHours`（1 至 24）。限制状态要求 `overseasPaused` 和 `blockedTags`，可选 `minimumTag`。调度字段过期时按本机默认计算。已认证的限制持续到更高版本有效快照明确解除。坏签名、超时和重启保留已验证限制。以同一原子存储更新已接受版本、摘要及限制，同版本不同内容视为冲突。远程配置的权限限于调度默认值和规则限制。

暂停仅移除海外规则授权，沿用现有选路重算和 WebKit 文档退役。站点手选、国内分类、独立隐藏位置授权各自求值。对仅获海外授权的在途请求和现有页面重算连接，对独立授权的页面保留其连接。
