# iOS Ver 5.0 網頁保護

適用 iPhone、iPad，最低 iOS 18.4。保護透過系統 WebKit、本機規則與頁面結構檢查實現。目前為開發候選；完整結果見[驗收紀錄](audit/ios-webkit-protection-2026-10-12.zh-CN.md)，四端差異見[功能清單](platform-features.zh-TW.md)。

## 開啟與復原

在「更多 → 設定 → 保護選項」中管理高風險網址、已知挖礦資源、已知指紋資源、系統強化及嚴格指紋限制。挖礦與指紋資源規則預設開啟，獨立於廣告過濾；暫停廣告過濾不會關閉這些規則。

- **風險頁面**：本機已知釣魚主機或多項高風險訊號會開啟原生阻止頁。結構檢查發現風險後替換並卸載網頁。可返回起始頁，或允許目前分頁存取相同完整網址 10 分鐘；切換網址即撤銷，其他分頁與私密視窗不共用。
- **資源誤擋**：頁面選單可暫時允許本站安全資源 10 分鐘，也可立即恢復攔截。這會同時暫停本分頁目前來源的挖礦與指紋規則，釣魚導覽檢查繼續生效。已載入的指令碼不會因恢復規則而自動撤回。
- **系統強化**：預設關閉。iOS 26.4 以上使用公開安全限制，關閉網頁 JIT；MTE 效果取決於裝置。舊系統保留預設 WebKit 保護並顯示限制，不宣稱同等強化。始終保留系統 Lockdown。可在網站設定指定單站選項，重新載入後生效。
- **嚴格指紋限制**：實驗功能，預設關閉。限制 Canvas 像素、WebGL 讀取與音訊結果，可能影響正常匯出、遊戲及音訊。在網站設定選擇恢復相容，再重新載入。

系統詐騙網站警告與已知主機 HTTPS 升級始終開啟。HTTPS 失敗採用系統的使用者決定回退偏好；App 不代替使用者略過系統警告。

## 本機檢查讀取什麼

導覽前檢查完整主機規則與網址風險。註冊網域依據包含私有後綴的 Public Suffix List，並由系統 URL 處理國際化名稱；共用託管的不同租戶不合併為同站。

頁面提交後，隔離指令碼立即讀取有限標題、密碼欄位數量、相關表單目的來源與 iframe 來源，之後每兩秒檢查一次，最多一分鐘。不讀取輸入值、密碼、驗證碼或正文，也不發出模型請求。合法跨站登入、單個國際化名稱或一般繪圖不單獨作為封鎖理由。同一文件切換站內路徑後，仍在原觀察視窗內依目前網址檢查。導覽、停止或關閉分頁會使舊檢查失效；新文件不會沿用前頁提示。

另一個頁面指令碼只記錄 Canvas、WebGL、Audio、Worker、WASM 的呼叫類別與有限次數。頁面可偽造這些訊號，因此只提供提示，不會觸發任意原生操作或自動判定未知挖礦。

## 規則來源與更新

內建版本 `2026101201`：190,191 個精確釣魚主機、312 個挖礦主機及四個明確指紋蒐集端點。完整來源、摘要與授權見 [security-rules-sources.json](../apps/ios/BrowserKit/Resources/security-rules-sources.json)。

- [Block List Project](https://github.com/blocklistproject/Lists)：釣魚主機；儲存庫 Unlicense，清單舊標頭仍標 MIT。上游標示最後更新為 **2026-07-06**，不能視為即時惡意主機情報。
- [NoCoin](https://github.com/hoshsadiq/adblock-nocoin-list)：已知瀏覽器挖礦主機，MIT。
- [EasyPrivacy](https://easylist.to/pages/licence.html)：選取明確蒐集端點，沿用本專案選擇的 CC BY-SA 3.0 規則資料授權。
- [Public Suffix List](https://publicsuffix.org/list/)：MPL 2.0，保留原始授權標頭。

規則包使用 Ed25519 驗證簽章，限制大小、網域格式、項目數、版本與有效期限。此版**隨 App 更新規則，沒有線上安全規則訂閱服務**；廣告過濾的自動更新開關只控制 EasyList/EasyPrivacy。內建包過期後繼續使用並提示更新 App。簽章不能證明每個上游網域仍然惡意，也不能取代維護與誤判處理。

## 已知邊界

結構檢查發生在頁面開始載入之後，不能保證先前沒有請求或資料傳送。一分鐘之後新增的表單不在本輪觀察視窗內。未知 fetch、XHR、WebSocket 外傳、逐指令碼 CPU 消耗及任意 HTTPS 回應正文沒有被完整檢查。

嚴格指紋限制屬於頁面 API 包裝：Worker、OffscreenCanvas、快取函式及頁面恢復原始函式可能繞過。保留 WebKit 自身隱私能力，但公開開關不能完整等同 Safari 的進階指紋保護。V8 位元組碼與完整 DNS/CNAME 檢查沒有移植到 iOS。

模擬器可驗證導覽、資源攔截與介面，不能證明實體裝置 MTE、耗電、實際攻擊偵測率或正式發行資格。
