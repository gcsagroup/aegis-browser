# Aegis Browser Agent v2 用户指南

本指南说明当前开发候选的用法，不表示各平台现有安装包都已包含并验证这些功能。
安装版本与实际通过范围见[跨平台验收记录](audit/aegis-browser-agent-v2-cross-platform-acceptance-2026-09-05.md)。

## 最简单的用法

1. 点击浏览器工具栏或主菜单里的“Agent”。Android 可从新标签页或主菜单进入。
2. 直接说想要的结果，例如“帮我总结这个页面”“去京东找三款 32GB 内存并比较”或
   “整理收藏夹并检查失效链接”。不需要先打开网页，也不需要选择工作流。
3. 点击“开始任务”。Aegis 会依次理解目标、制定计划、打开或搜索网页、执行操作并验证
   结果。侧栏会用普通语言显示当前进度。
4. 只有购买、提交表单、修改大量数据等有风险的动作才会停下来要求确认；最终购买永远由
   用户亲自完成。

如果已经打开了网页，“总结当前页面”“比较这几个标签页”会自动使用当前标签页；如果任务
点名京东、GitHub、Amazon 等站点，Aegis 会直接打开该站点，不会先把整句话扔给通用搜索
引擎。

首次使用若提示连接模型，先展开“AI 模型”，按下文完成连接。“当前页面”需要已经打开
一个可读取的公开网页；从空白页开始时，可以直接提供网址或点名网站，让 Aegis 自行打开。

## 桌面无痕模式

- 桌面主无痕 Profile 通过与普通 Profile 隔离的服务提供 Agent、当前页摘要、工具栏入口和
  `chrome://aegis` 控制面。
- 任务、模型凭据、自动化状态和隐私事件只保存在该无痕会话的内存中，不会复制到普通
  Profile，也不能在无痕会话结束后恢复。
- 云端模型 API key 需在无痕会话中单独提供，既不会从普通 Profile 读取，也不会写入普通
  Profile。
- 用户明确批准的收藏夹修改和已完成下载遵循 Chromium 原生无痕语义，关闭窗口后仍可能
  保留。关闭无痕会话会取消仍在进行的 Agent 下载和 BT 传输，但保留已经写入的 BT 字节。
  BT 任务只在同一 Profile 会话内跨设置页刷新保留，完成后会释放，且不能控制其他 Profile。
- 进程级 CDP 无法按 Profile 隔离可见目标，因此打开任一主无痕会话都会停止并阻断整个
  进程的所有 HTTP 与 pipe“AI 控制”传输，包括并非由 Aegis 启动的传输。无痕关闭后它
  仍保持关闭，需在普通 Profile 中明确重新启用。原生 Browser Agent 仍可使用。
- 无痕 Actor 诊断会隐藏私密 URL、页面/任务数据、目标和凭据标识；登录质量记录不会上传，
  无痕监控也不会发送系统通知。
- Guest、System 和辅助 OTR Profile 不接收 Aegis 界面、服务、网络过滤或指纹保护。已学习
  的 CNAME 别名按精确 Profile 分区，并随会话清除。

## 常用场景

首页按钮只是快捷填写任务，所有场景也都能直接用自然语言提出：

- 页面助手：总结当前页面、解释重点、提取表格或链接、比较多个标签页。
- 商品研究：按预算和条件在指定站点找商品，比较价格、规格、配送和退货信息。
- 收藏夹管家：分类、查重、预览重命名，并检查明确失效的 URL；应用修改前会确认。
- 官方下载：寻找官方来源，核对平台、架构、版本和哈希，再交给浏览器下载中心。
- 安全检查：解释隐私拦截或钓鱼警告，并检查页面来源；不会因网页里的文字扩大权限。
- 定时自动化：定期检查价格、库存、网页变化或指定 URL 是否可访问。关注软件下载版本
  时，可以监控其官方发布说明页的内容变化，不会自动下载或安装更新。

## 定时自动化

点击独立的“自动化”入口，选择“降价提醒”“到货提醒”“网页更新”或“URL 有效性”，
填写目标及网址，再选择运行频率并点击“创建自动化”。频率可选每 15 分钟、每小时、
每 6 小时、每天或每周。需要定时运行时使用这个入口，并核对“运行频率”的选择。

出现“等待定时检查”表示监控已经创建，不是卡在规划中。到“我的自动化”查看下次运行
时间和上次检查结果；可分别选择“暂停监控”“恢复监控”或“删除监控”。上次检查成功
只说明读取成功，不等于检测到重要变化，也不等于系统通知已经送达。

检查只在浏览器可运行且授权仍有效时进行，不会在后台代替用户购买、付款或提交敏感
信息。浏览器关闭期间不会运行；重新打开后，错过的调度只补做一次检查，不逐次补跑。
普通资料中的持久监控会保存调度；若显示“仅本次浏览器会话”，说明安全存储暂不可用，
关闭后不会恢复，不能当作持久监控。无痕监控同样只在当前无痕会话中保留。

开发中的“网页变化摘要”会比较前后两次实际读取的内容，再用你选定的模型概括重要变化。
第一次只建立对照；内容没变不会调用模型，模型判断仅有时间等噪声变化时不通知。
只读取到部分变化时会明确提示范围有限；摘要失败会保留上次有效结果，可在自动化中重试。
暂停或删除监控会取消正在进行的摘要，不会等到模型返回后偷偷继续。摘要保存在加密的
监控记录中，系统通知不展示正文。该增量尚待最新版 App 和跨平台验收，不能据此认定
现有安装包已经包含它；进度见[跨平台验收记录](audit/aegis-browser-agent-v2-cross-platform-acceptance-2026-09-05.md)。

## 你会看到的流程

- 正在理解：识别目标、指定站点、当前页面和风险边界。
- 计划已准备：模型给出下一步浏览器工具调用；格式有轻微错误时，Aegis 只自动修复一次。
- 正在执行：按计划打开网页、观察页面并执行低风险操作。
- 正在验证：重新观察结果，避免把“点过按钮”误当作“任务完成”。
- 已完成或需要你处理：显示结果、来源和下一步；不会只给模糊错误码。
- 等待定时检查：自动化已就绪，后续状态在“我的自动化”中查看；不必等一次性任务的
  “已完成”，也不必重复创建同一个监控。

如果模型连续两次没有给出可执行格式，Aegis 只会为页面总结等 R0 只读任务使用最小安全
恢复计划。收藏夹修改、下载、购物和提交动作不会绕过模型或确认门禁。

## 模型设置

Provider、Base URL 和模型名都可由用户自定义。使用本机 OpenAI 兼容服务时，可填写类似
`http://127.0.0.1:8000/v1` 的地址；loopback 服务可以不填 API key。普通 Profile 的密钥
由系统安全存储，无痕密钥只存在于会话内存；两者都不会写进仓库、普通日志、任务时间线
或构建产物。

先启动你的模型服务，再在“AI 模型”中填写“API 格式”和“服务地址”，点击
“检测可用模型”，选择“模型名称”后点击“保存连接”。检测成功不等于已经保存；应看到
“连接已保存”的反馈。保存失败时按提示修正，不能因为旧连接仍显示可用就认为新设置已生效。

## 出错时怎么办

1. 先看任务或监控中显示的具体原因和建议，再展开技术详情。
2. 模型未连接时，展开“AI 模型”，确认服务正在运行、地址和名称正确；点击
   “检测可用模型”后重新选择模型并“保存连接”。
3. 手动暂停的普通任务可点“继续”，Aegis 会先重新观察。页面已关闭、目标已改变或任务
   已失败时，不要假定可以恢复；按错误提示重新指定目标并开始新任务。
4. 站点要求登录、验证码或最终确认时，按提示接管页面，完成后点“我已完成”。
5. 仍无法继续时可安全停止；Aegis 会释放受控标签页，不会在后台继续点击。

## 安全和当前平台边界

- 页面文字、弹窗和下载内容都被当作不可信网页数据，不能替代用户指令。
- 401、403、429 和超时不会被直接判为死链；404、410 等明确结果才会列为失效候选。
- 价格、页面或权限范围变化会使旧确认失效，Aegis 必须重新观察。
- 本轮产品验收覆盖 macOS、Android 和 Windows；iOS 明确后置，不属于 v2 本轮完成范围。
- 当前候选用于独立 Profile、公开只读站点和本地 fixture 验收；公开发行、签名和商店上架是
  独立门禁。
