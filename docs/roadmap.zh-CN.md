## 状态用语

- **历史原型：**用于证明方向，不属于当前交付物。
- **已进源码：**代码或补丁存在；构建和运行状态另行判断。
- **源码已同步：**补丁谱系、overlay 与外部 checkout 一致。
- **门禁通过：**明确命名的源码、产物、平台和代表性测试范围同时通过。
- **发行合格：**同一可分发产物通过身份、信任、签名、安装、隐私、平台和发布门禁。

## 当前结论 — 2026-08-28

源码集成已同步到 56 个顶层 Chromium 补丁，另含 2 个嵌套 V8 补丁。最新带身份清单的本地 build-tree 只覆盖 54 个顶层补丁及这 2 个 V8 补丁，资格为 `diagnostic-only`；0055、0056 尚无匹配的产物证据。

项目整体仍为**发行 No-Go**。目前没有受信任的当前源码分发包、产品身份、Developer ID 签名、公证、安装 App 验收或当前源码 Android 包。

## 历史阶段

### Phase 0 — 脚手架

Monorepo、三语产品页和 Core 策略原型确定了产品方向。

### Phase 1 — Extension 原型

MV3 Extension 曾演示部分跟踪器、钓鱼和隐私摘要思路，目前不再是产品或发行目标。

### Phase 2 — Core 原型

链接清洗、Cookie 分类、PII 脱敏、钓鱼启发式和生成策略资产进入可复用、可测试代码。研究性质评测器仍与浏览器决策隔离。

## Phase 3 — Chromium fork

### M0：基线与恢复 — 已完成

- Chromium 固定为版本 `151.0.7922.77` 和 base commit `ff37cfca210138f2a40b843b4a8195ab7e4fc7ff`。
- 已建立本地恢复点和证据保留边界。

### M1：Browser-only 收敛与快速门禁 — 已完成

- Chromium Browser 是唯一产品线。
- Workspace 具有冻结的 JavaScript 依赖和可重复的快速质量门。

### M2：Chromium 集成与构建身份 — 部分完成

- 外部 Chromium checkout 与 56 个顶层补丁及 2 个嵌套 V8 补丁一致。
- 最新 finalized 身份清单只覆盖 54 补丁 Chromium HEAD 加 2 个嵌套 V8 补丁，不对应当前 0056 源码 HEAD。
- 仍需为当前源码 0055/0056 完成构建、受影响原生测试、代表性运行验证和新的身份绑定产物。
- 现有 build-tree 输出只是本地开发证据，不是 RC 或分发包。

### M3–M4：安全边界与稳定性 — 部分完成

- Chromium 原生跟踪、链接、Cookie、钓鱼、指纹、下载、摘要和本地自动化控制已进入源码。
- 所选历史原生、浏览器和运行门曾在明确命名的较早补丁 HEAD 上通过。
- MinerGuard 与 V8 bytecode shadow 保持仅观察。研究评测器不能授权阻断或生产安全声明。
- 完整出站归因、遥测/更新/崩溃报告审查、代表性功能行为矩阵、启动压力、误报评测和当前 HEAD 重跑仍未完成。

### M5：Android — 阻塞

- 当前证据集中没有合格的 x86-64 Linux 构建环境。
- 没有带身份清单的当前源码 APK/AAB，也没有当前源码的真机验收。
- Android 页面摘要和平台特定行为需要基于当前源码验证。

### M6：内部发行候选 — 待完成

内部 RC 需要干净、带身份清单的当前源码构建；受影响测试和运行门；产品身份；签名与公证准备；打包；安装 App 验收；隐私/出站审查和回退证据。以上任何一项都不能由源码同步推断。

### M7：文档与发布边界 — 进行中

- 公开 README、变更日志、架构、路线图和研究映射维护英文、简体中文和繁体中文版本。
- 带日期的审计记录属于历史快照，不覆盖本路线图。
- 源码发布、安装包发布和生产部署始终是不同决策。

## GitHub 源码同步

2026-08-28 的授权只覆盖通过 SSH 将源码分支同步到 `git@github.com:gcsagroup/aegis-browser.git`，不覆盖 Git tag、GitHub Release、二进制、签名凭据、公证、Play 上传或生产部署。

## 发行退出条件

1. 在干净状态提交并重放精确的当前源码与全部嵌套补丁谱系。
2. 在合格主机上生成带身份清单的当前源码 macOS 产物和 Android 产物。
3. 在这些精确产物上通过受影响单测、浏览器、运行、隐私、出站、性能和代表性站点门禁。
4. 完成产品身份、签名、公证、打包、安装、升级、回退和真实设备验收。
5. 针对精确发行候选复核文档、第三方声明、安全/隐私文案和分发授权。
