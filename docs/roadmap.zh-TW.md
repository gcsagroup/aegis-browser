## 狀態用語

- **歷史原型：**用於證明方向，不屬於目前交付物。
- **已進原始碼：**程式碼或補丁存在；構建和執行狀態另行判斷。
- **原始碼已同步：**補丁譜系、overlay 與外部 checkout 一致。
- **門禁通過：**明確命名的原始碼、產物、平台和代表性測試範圍同時通過。
- **發行合格：**同一可分發產物通過身分、信任、簽名、安裝、隱私、平台和發布門禁。

## 目前結論 — 2026-08-28

原始碼整合已同步到 56 個頂層 Chromium 補丁，另含 2 個巢狀 V8 補丁。最新帶身分清單的本機 build-tree 只涵蓋 54 個頂層補丁及這 2 個 V8 補丁，資格為 `diagnostic-only`；0055、0056 尚無匹配的產物證據。

專案整體仍為**發行 No-Go**。目前沒有受信任的目前原始碼分發套件、產品身分、Developer ID 簽名、公證、安裝 App 驗收或目前原始碼 Android 套件。

## 歷史階段

### Phase 0 — 鷹架

Monorepo、三語產品頁和 Core 策略原型確定了產品方向。

### Phase 1 — Extension 原型

MV3 Extension 曾示範部分追蹤器、釣魚和隱私摘要思路，目前不再是產品或發行目標。

### Phase 2 — Core 原型

連結清理、Cookie 分類、PII 脫敏、釣魚啟發式和生成策略資產進入可重用、可測試程式碼。研究性質評測器仍與瀏覽器決策隔離。

## Phase 3 — Chromium fork

### M0：基線與恢復 — 已完成

- Chromium 固定為版本 `151.0.7922.77` 和 base commit `ff37cfca210138f2a40b843b4a8195ab7e4fc7ff`。
- 已建立本機恢復點和證據保留邊界。

### M1：Browser-only 收斂與快速門禁 — 已完成

- Chromium Browser 是唯一產品線。
- Workspace 具有凍結的 JavaScript 相依套件和可重複的快速品質門。

### M2：Chromium 整合與構建身分 — 部分完成

- 外部 Chromium checkout 與 56 個頂層補丁及 2 個巢狀 V8 補丁一致。
- 最新 finalized 身分清單只涵蓋 54 補丁 Chromium HEAD 加 2 個巢狀 V8 補丁，不對應目前 0056 原始碼 HEAD。
- 仍需為目前原始碼 0055/0056 完成構建、受影響原生測試、代表性執行驗證和新的身分綁定產物。
- 現有 build-tree 輸出只是本機開發證據，不是 RC 或分發套件。

### M3–M4：安全邊界與穩定性 — 部分完成

- Chromium 原生追蹤、連結、Cookie、釣魚、指紋、下載、摘要和本機自動化控制已進入原始碼。
- 所選歷史原生、瀏覽器和執行門曾在明確命名的較早補丁 HEAD 上通過。
- MinerGuard 與 V8 bytecode shadow 保持僅觀察。研究評測器不能授權阻斷或正式環境安全聲明。
- 完整出站歸因、遙測/更新/崩潰報告審查、代表性功能行為矩陣、啟動壓力、誤報評測和目前 HEAD 重跑仍未完成。

### M5：Android — 阻塞

- 目前證據集中沒有合格的 x86-64 Linux 構建環境。
- 沒有帶身分清單的目前原始碼 APK/AAB，也沒有目前原始碼的真機驗收。
- Android 頁面摘要和平台特定行為需要基於目前原始碼驗證。

### M6：內部發行候選 — 待完成

內部 RC 需要乾淨、帶身分清單的目前原始碼構建；受影響測試和執行門；產品身分；簽名與公證準備；封裝；安裝 App 驗收；隱私/出站審查和回退證據。以上任何一項都不能由原始碼同步推斷。

### M7：文件與發布邊界 — 進行中

- 公開 README、變更日誌、架構、路線圖和研究映射維護英文、簡體中文和繁體中文版本。
- 帶日期的稽核記錄屬於歷史快照，不覆蓋本路線圖。
- 原始碼發布、安裝套件發布和正式環境部署始終是不同決策。

## GitHub 原始碼同步

2026-08-28 的授權只涵蓋透過 SSH 將原始碼分支同步到 `git@github.com:gcsagroup/aegis-browser.git`，不涵蓋 Git tag、GitHub Release、二進位檔、簽名憑證、公證、Play 上傳或正式環境部署。

## 發行退出條件

1. 在乾淨狀態提交並重播精確的目前原始碼與全部巢狀補丁譜系。
2. 在合格主機上生成帶身分清單的目前原始碼 macOS 產物和 Android 產物。
3. 在這些精確產物上通過受影響單元測試、瀏覽器、執行、隱私、出站、效能和代表性網站門禁。
4. 完成產品身分、簽名、公證、封裝、安裝、升級、回退和真實裝置驗收。
5. 針對精確發行候選複核文件、第三方聲明、安全/隱私文案和分發授權。
