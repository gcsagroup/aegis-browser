# TypeSafe AI 决策接入

## 范围

TypeSafe AI 的 Jev 接在 Browser Agent 的目标理解入口，用于选择已有工作流和入口类型。它输出有限选项及置信度；计划生成、工具参数和最终回答继续由用户配置的生成模型处理。本次不实现多个生成模型之间的自动切换。

该能力默认关闭。启用后，即使生成模型运行在本机，输入的任务目标仍会发送给 TypeSafe；设置页必须在启用前说明这一点。未启用、无有效密钥或隐身 Profile 不调用 TypeSafe。

## 接口与数据边界

官方接口核对日期：2026-09-21。

- 固定接口：`POST https://api.typesafe.ai/v1/systemone`。
- 模型：`jev-latest`；这是服务商可更新的别名，行为验收需记录实际返回的版本。
- 鉴权：独立的 TypeSafe Bearer API key，不复用 OpenAI、Anthropic、Gemini 或本机模型的凭据。
- 请求只包含用户输入的任务目标和浏览器预定义的问题。用户主动写进目标的内容也会被发送；不要将页面 DOM、历史、Cookie 或其他模型密钥附加到请求。
- Choice 答案必须属于预定义枚举，类型、置信度、概率分布和选中项均需验证。
- TypeSafe 不生成 URL、搜索词、摘要或工具调用。入口参数由浏览器构造，并继续经过现有用户意图约束。

参考：[API reference](https://docs.typesafe.ai/api)、[Quick start](https://docs.typesafe.ai/introduction/quickstart)、[Introduction](https://docs.typesafe.ai/introduction)。

## 执行与回退

默认路径保持已有模型路由。启用 TypeSafe 后，对符合条件的目标执行一次最多 2 秒的决策请求。两个答案的置信度均须达到 0.8，且选中项必须与概率分布一致。合格结果选择已有工作流；低置信度、无效结果、网络错误、限流和超时回退到原有路径，不在入口中循环重试。

决策本身不授予工具权限。任务授权卡、来源和标签页范围、下载或购物的最终确认、用户目标中的否定约束继续由浏览器维护。显式 URL 和当前页面入口保留原有处理逻辑。

密钥只通过密码字段写入浏览器进程，持久化时加密；WebUI 只读取“是否已配置”等状态。固定服务地址，拒绝重定向，避免鉴权头转发到其他目的地。关闭能力、清除或替换密钥、取消任务以及销毁 Profile 时，应使在途请求失效，旧结果不能启动后续模型调用。

## 配置与使用

1. 在包含本次代码的 Aegis 构建中打开 Browser Agent，先配置用于计划和回答的生成模型。
2. 展开独立的 TypeSafe 设置，阅读任务目标发送说明，输入从 [TypeSafe 控制台](https://console.typesafe.ai/) 取得的 API key，开启后保存。不要将密钥提交到 Git、PR 或测试日志。
3. 输入需要搜索入口的新任务。显式网址、已绑定当前页和浏览器原生入口继续走原有逻辑；这些任务不会为展示“接入成功”而额外请求 TypeSafe。
4. 检查任务计划及授权范围，再按现有流程执行。关闭 TypeSafe 或清除密钥可恢复原有路由。

## 验收

| 层级 | 需要证明的行为 |
| --- | --- |
| 协议单测 | 请求使用官方 schema；合法枚举通过，未知枚举、错误类型、低置信度、缺失或矛盾概率拒绝。 |
| 网络单测 | 固定目的地、独立鉴权、Cookie 排除、重定向拒绝、响应大小与超时限制、错误回退及取消。 |
| 服务回归 | 默认关闭无新增网络；失败只回退一次；隐身禁止；配置变化后的过期回调被丢弃；已有意图与权限约束不变。 |
| WebUI | 默认关闭；云端发送说明可见；密钥写入后不回显；保存失败可见；清除后禁用；生成模型设置保持独立。 |
| 原生集成 | 最终代码进入固定 Chromium GN 目标，执行相关 GTest，并在侧栏验证设置、启动、回退和取消。 |
| 真实服务 | 使用有权限的 TypeSafe key，记录返回模型版本、成功/失败、延迟与回退；不记录密钥或完整任务目标。 |

仓库基础质量门、独立 Review、GitHub CI、Chromium 构建和真实 API 联调分别报告。Node WebUI 测试或静态 GN 检查不代表 C++ 行为测试已通过。没有实际执行的测试不标为通过。

## 回滚

在 Agent 设置中关闭 TypeSafe 即恢复原有模型路径；清除密钥同时关闭功能。代码回滚通过普通可审查 revert，保持现有生成模型配置。
