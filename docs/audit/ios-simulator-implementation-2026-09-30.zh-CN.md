# iOS 模拟器实施与验收 · 2026-09-30

## 交付范围

本轮在既有 `apps/ios` 工程上实施，目标是 iPhone / iPad Simulator。沿用 `com.gcsa.aegis.ios.app` 和固定构建路径。真机、正式签名和公开分发按用户要求不在本轮范围内。

本次历史验收的版本与测试数字以文末的最终验收记录为准。早期失败结果保留，不用历史通过数替代本轮结果。

## 已实现

- 浏览器：普通标签恢复、工作区保存/追加恢复/撤销、收藏与历史入口、页内查找、分享与打印入口。iPad 保留宽屏侧栏。
- 真实网页助手：选择最多 5 页，读取可见正文；排除隐藏内容、输入值、密码、Cookie，拒绝敏感表单。读取前绑定页面身份，发送前再次核对。正文超长时提示截断。
- 模型连接：兼容 Chat Completions、Anthropic、Gemini 接口；连接检测、模型选择、Keychain 保存、个人信息脱敏、秘密拒发、重定向拒绝、响应大小上限、未完成输出拒收和引用编号核对。
- 收藏：保留原有两次明确确认、变更预览、撤销和重启后恢复机制；补充真实 HTTP 失效链接检查。
- 下载：实际 HTTP(S) 传输、进度、暂停/续传/取消/重试、后台传输、持久记录、SHA-256 校验、直接导出至系统“文件”与分享入口。校验不一致时不交付文件。支持 HTTPS 与本机 HTTP；远端明文 HTTP 受系统传输策略限制。
- 保护：从共享规则生成 31 条 WebKit 跟踪拦截规则；编译失败时停止加载。支持当前站点例外、历史清除、普通网站 Cookie/存储/缓存清除。
- 三语和界面：简体、繁体、英文资源；替换用户可见的内部术语；修复键盘遮挡与大字体下底栏越界。
- 系统交接：保留分享扩展短期网址交接；增加外部网址严格解析与打开确认。Safari 只读授权完成后交接网址，不交接正文或模型操作。

## 本轮实际发现并修复的问题

1. 关闭模拟器签名导致 Keychain 相关用例失败：恢复 Xcode 默认模拟器签名。
2. WebKit 不接受原跟踪规则中的正则组合：调整生成表达式，并新增真实 WebKit 编译验证。
3. 系统确认框重复暴露发送按钮：改为独立发送确认页，清楚列出服务、模型与资料。
4. 下载和模型设置完成后键盘仍遮挡结果：在开始传输、检测和保存时结束输入。
5. 暂停回调可能晚于用户继续下载：增加暂停中的状态，恢复数据写完后才能继续。
6. 大文件摘要在界面线程计算：移至后台任务，记录落盘后才结束后台事件。
7. 大字体将 iPhone 助手按钮挤出屏幕：限定图标尺寸并调整底栏间距，保留可访问名称。
8. iPad 侧栏标识传播到子项，旧断言找不到容器：显式定义可访问性容器。
9. 通用分享入口不能证明文件已经导出：增加直接文件导出入口，以系统选择器完成回调作为保存结果。
10. 极大字体横屏检查过于宽松：增加旋转完成等待与地址栏/工具栏边界断言，固定导航图标尺寸，手机横屏不展开平板侧栏。测试截图改用设备整屏，避免 App 截图的旋转裁剪异常。

## 验证方法

- 原有安全、授权、收藏一致性和恢复测试继续运行。
- 新测试使用真实 WebKit、URLSession、Keychain、文件系统和模拟器 UI。
- 本机服务只监听 `127.0.0.1:8768`，文章、下载文件和模型回答均为合成数据。真实读取/发送/回答/引用链路通过，不等于真实远端模型质量通过。
- 下载使用已知文件，并以 SHA-256 核对；测试覆盖暂停/续传、错误哈希拒收、取消、切到后台约 5 秒后返回，以及实际系统文件导出。
- UI 覆盖普通/私密、敏感页面拒绝、收藏撤销与重启恢复、工作区、三语设置、大字体、深色、横屏及 iPad 侧栏。
- 使用 Apple 官方公开 HTML 页面检查加载与页内查找。此前 example.com 在 iPad 连续超时，宿主机也曾连接超时，随后恢复；原始失败记录保留。未将超时改为跳过，也未以本机页面替代公网验收。
- 固定脚本实际执行，重复使用同一构建目录与两部具名模拟器，每次构建递增版本，不擦除模拟设备。

## 仍需单独验证的范围

- 外部模型服务的真实凭据、服务差异及回答质量；本轮只用合成模型完成网络闭环。尚未完成与 macOS、Windows、Android 的同任务结果对照。
- Safari 与分享扩展在真实宿主里的完整交接、任意网站上传/登录兼容性、PDF 保存、VoiceOver 全流程、长时间后台与系统重启恢复。
- Xcode 27 的 DeviceHub 图形入口曾停在“Installing system components…”，最终 Computer Use 打开入口仍超时。命令行模拟器及 XCTest UI 操作可运行；图形管理窗口启动未验收。
- 下载由系统管理后台中间重定向，应用检查起始和最终地址；不能宣称后台逐跳拦截。强制退出、断网、服务器不支持续传时不保证持续传输。
- 自动全网检索、BT/磁力、多连接加速、跨设备同步及 Chromium 专有内核能力尚未实现。当前研究/购物助手比较用户选定的网页，不自动登录、下单或付款。
