## 其余文案范围：建议做一批有限清理

1. 固定界面文字：暂停/接管/恢复、预算不足、页面丢失、原生存储失败、只读降级等罕见时间线仍存在英文诊断字符串。建议按状态表补齐三语，将原始原因放到技术详情，统一验收每类代表分支。
2. 模型正文：摘要、比较说明和整理方案是模型基于网页或已授权浏览器数据生成的自然语言。本轮处理了已知来源标签和英文输出缺口，其他错字、表达不自然、混合语言或事实表述仍需代表语料评估。建议优先约束结构和引用，不为每句自动再调用一次模型；确需校对时只做一次且保持数字、网址和引文。
3. 可访问性：窄侧栏和 Tab 入口有既有证据，真实旁白听读仍未完成。建议单独验收状态播报、焦点位置、批准和失败提示；不要把可访问性树可读当作听读通过。

完成标准：选定状态全部有三语文本；代表模型语料按事实与语言分开评分；旁白操作有实际听读记录。暂不扩大到整个 Chromium 的翻译清理。

## 性能与输入范围：先建立可比基线

057 的描述性采样为候选导航 P95 9.3 ms、官方对照 7.3 ms，CPU 平均 0.1555% 与 0.1000%，RSS 峰值约 1.06 GiB 与 1.22 GiB。两者 Chromium 补丁版本和配置不同，不能据此认定具体功能造成退化。

建议先选相同内核、相同编译配置与测试资料的对照，固定冷/热启动、导航、空闲和 Agent 执行场景。统一采集后再按热点修复，避免用调整配置造成的差异冒称产品优化。建立新的对照构建涉及额外时间和磁盘，不在本轮自动执行。

输入节省另算：057 的全链输入相比 041 降低 21.33%，未达到 30% 目标，且高于 047。应保留来源身份和安全证据，重点评估重复上下文、工具描述及失败恢复成本；同时报告输入量、响应耗时、成功率和重试次数。本轮收藏固定读取预计减少一次模型请求，是否达到整体目标仍要在相同任务样本实测。

完成标准：可比对照身份完整、全链口径一致、性能收益不以任务成功率或证据完整性下降换取。
