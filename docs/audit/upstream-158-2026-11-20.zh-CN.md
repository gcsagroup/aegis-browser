在途代理请求的浏览器回归验证阻断屏障匹配并终止一个请求、注册数减少一个、页面收到失败且源站没有收到请求。同一配置可以同时持有其他页面请求。

## 拒绝规则更新时保留在途请求

拒绝尚未发布的候选规则时，异步存储只撤销已准备的日志项，当前策略版本仍供在途重定向使用。浏览器回归在代理收到请求后拒绝冲突规则，再放行重定向并检查代理响应。取消测试同时保留同一配置下两个文档的请求，验证另一个文档仍可读到原代理的响应。

预取使用与浏览器进程相同的工厂构建入口，同时保留私有终端和测试拦截器。macOS 权限提示结束时会释放已被系统隐藏的弹窗持有的锁，AIM 窗口测试等待原生窗口可见后再请求呈现。桌面验收选择包含规则恢复与冷启动监视器。Android 补丁使用与其同步协调器兼容的夹具。菜单指标检查按两个已命名的直方图枚举分别核对 C++ 和 XML 中的持久化编号。

## macOS 权限提示期间的地址栏焦点恢复

AppKit 隐藏 AIM 弹窗后会将焦点还给浏览器窗口。在全 WebUI 地址栏模式下，只要 AIM 仍持有权限提示，系统恢复焦点时就保留该弹窗。原生回归激活 AIM 窗口，再由 AppKit 隐藏它，检查窗口持有关系、权限提示状态，以及权限提示结束后主动聚焦地址栏的行为。

## 地址栏权限提示的创建与回滚

创建失败时仅归还本次取得的弹窗保护。隐藏窗口仍由原提示持有，第二个失败请求不会释放它。测试分别覆盖 Views 和 WebUI 地址栏，以及原生 Escape 和渲染器处理。WebUI 地址栏用例隔离了无关的 Aegis Agent 默认固定按钮。
