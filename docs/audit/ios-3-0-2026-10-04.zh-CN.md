# iOS Ver 3.0 功能改进与验证

日期：2026-10-04。范围：本地源码、iPhone/iPad 模拟器、未签名设备架构构建。基于 `a4480b4ab0c04b8f486a01f7486ecdb15f2fed25`，工作分支 `codex/ios-stability-20261004`。

## 完成标准

按五组建议完成实现后统一测试：资料可恢复、多标签按需加载、下载与收藏管理、三种模型接口流式输出、稳定性与可访问性。失败项修复后重新验证。真实设备与真实模型需要独立操作证据。

## 实现结果

1. **资料恢复**：下载和工作区提供原件导出、重新读取、备份选择和备份后重置。恢复失败保留原记录；损坏记录不会被正常保存覆盖。完成文件单独保存收据，通过哈希校验找回“文件已下载、总记录写入失败”的项目。
2. **标签性能**：恢复 10、30、50 个标签时只创建当前页的 WebView。闲置普通页可释放并恢复滚动位置；保留表单编辑、媒体播放、框架、实际浏览历史和助手正在读取的页面。忽略已释放页面的迟到回调，连续崩溃停止自动重载。模拟器记录实际恢复时间和驻留数量，不据此推断真机内存与耗电。
3. **资料管理**：收藏、历史和工作区支持搜索与排序。下载支持搜索、筛选、排序、批量管理、系统文件预览、容量显示和 1–4 个并发任务。仅移除记录后可主动找回文件；同时移除文件时先进入回收站，可恢复，永久清空需再次确认。暂停任务的续传资料一起恢复。
4. **流式助手**：兼容接口、Anthropic 和 Gemini 支持增量显示、阶段提示和错误分类。未完成内容明确作为草稿；取消、断流或无效引用不能保存为完成结果。接收全部结束信号并核对引用后才允许保存。测试包含 UTF-8 分片、错误状态码、JSON 回退和实际本机 HTTP 断流。
5. **操作与稳定性**：大字体布局、可访问性控件说明与触控区域检查、iPad 键盘新建/关闭/地址输入/查找；低磁盘拒绝新下载、队列推进、网络中断与续传。查找打开时输入框自动聚焦；地址进入编辑时选中完整网址。

所有新增界面提示提供简体中文、繁体中文和英文。普通/私密浏览、原有来源确认和保存授权流程继续保留。

## 验证结果

本轮新增 14 项原生测试和 6 项界面测试；按用户要求先完成实现，再统一测试并修复发现的问题。

- **Ver 3.0 (50)，全量**：iPhone 17 / iOS Simulator 26.5 为 177 项通过、3 项 iPad 专属用例跳过；iPad Air 11-inch (M4) / iOS Simulator 26.5 为 180 项全部通过。两台均为 0 失败、0 运行时警告。
- 两台使用同一构建；运行前后 `apps/ios` 输入 SHA-256 清单完全一致。输入清单哈希为 `5dce56c5127c7c9cb8c00b1cb84a2014e2ed54ac58fa2ca77c7b29e7b160f89d`。
- 产品 Swift 行覆盖率：iPhone 86.24%（12475/14466），iPad 88.01%（12732/14466）。覆盖率包含主 App 和扩展源码，不代表未操作的真实扩展宿主已通过。
- **最终下载布局，Ver 3.0 (52)/(54)**：预览、导出、镜像和后台传输在 (52) 两台各 4 项通过；批量流程在 (54) 两台各 1 项通过。两个版本产品源码一致，后者只修正测试滚动定位。按钮改为固定竖排，双机截图确认文字完整。全量测试后唯一的产品源码变化为这处下载操作布局；源码差异清单已保存。
- **Ver 3.0 (55)，未签名 Release**：固定路径下 `generic/platform=iOS` 编译成功；主 App、Safari 扩展和分享扩展均为 `3.0 (55)`、`arm64`。相对 (54) 只改构建号和生成工程，产品及测试源码一致。产物没有签名和设备描述文件，不能据此声明真机可安装。编译保留了 Release 下测试分支恒假的警告，不影响构建成功。
- 478 项界面资源的三语完整性和格式占位符一致；编译器提取的 444 项非空文案均包含在资源表内。
- 仓库 `quality:fast` 已通过，核心 29 个测试文件 / 193 项测试，以及脚本、合同、构建与访问计量检查通过。本机合成服务脚本 7 项代表性自测通过。
- 已人工核对双机原生操作截图，包括记录恢复、系统文件预览、流式取消、大字体横屏和 iPad 键盘查找；下载按钮布局与批量恢复在 Ver 3.0 (52)/(54) 单独检查通过。

## 修复与复测

后续布局验证中，(51) 操作测试通过但截图显示按钮文字隐藏，未接受为最终界面。改为固定竖排后，(52)/(53) 的批量测试受空列表和恢复提示移出视野影响；已核对空清单与两份保留文件，再修正滚动定位，在 (54) 双机通过。保留这些失败与读回证据。

Ver 3.0 (48) 全量保留 iPhone 177 通过 / 3 跳过、iPad 176 通过 / 4 失败；Ver 3.0 (49) 针对性测试修复焦点、取消和后台下载，另发现测试错误地使用请求路径名定位服务器重命名的文件。该测试改为滚动后检查保存按钮及预期哈希；上述失败均已在 Ver 3.0 (50) 全量通过。

统一测试发现并修复：连接拒绝时镜像切换等待过久、地址栏编辑残留后缀、休眠页面恢复滚动失败、回收站遗漏暂停任务记录、流式输出尚未完成就检查最终引用、iPad 快捷键注册与查找输入焦点问题。保留早期失败记录，不将它们计为通过。全量回归又发现 iPad 查找面板显示后焦点未交接、取消按钮需要滚动，以及下载列表的测试定位问题：查找输入改为在原生面板显示完成后聚焦；取消按钮放到固定工具栏；下载测试先滚动到记录再断言。后台测试失败时已从模拟器读回 1,409,024 字节的完成文件，SHA-256 与收据一致，因此没有把按钮定位失败误判为下载未完成。
