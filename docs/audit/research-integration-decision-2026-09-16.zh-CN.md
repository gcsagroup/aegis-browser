# 研究整合取舍与验收边界

2026-09-17更新，公开论文及作者材料于9月16日复核。本报告区分论文方法、可复用材料、本机实验和产品能力。M4的R01–R05按原计划结束本轮限定试验：R01–R03证据不足，R04/R05保留有限测量和流程结果，未覆盖的范围明确记录。它们不解除M2/M3的产品验收条件，也不构成研究模型可默认上线的结论。

## 采用的工程方法

沿用浏览器现有执行器，按任务裁剪观察、绑定用户选择的完整地址、核对原生结果，并在接管和取消后撤销旧授权。多页研究由浏览器逐页读取，再由既有模型整理；研究存储只在用户明确点击后加密保存，无痕仅保留在会话内。论文没有被作为权限放行依据，也没有新增独立 Agent 框架。

## R01：保留独立规则裁剪，暂不引入 MINIM 模型

重新读取的 [MINIM 论文](https://arxiv.org/abs/2606.13949)为 v1，提交于 2026-06-11；ICML 接收情况来自作者在 arXiv 的说明。本轮递归核对作者仓库的 13 个路径，未找到代码许可证或权重文件；数据卡的 MIT 标注不能替代实现和权重许可。数据卡另指向的仓库访问失败，也保留在预检中。

现有独立规则裁剪已经进入浏览器；本轮没有运行 MINIM 权重，没有可比较的必要元素保留率和任务成功率，因此不能宣称达到论文收益，也不能宣称达到计划中输入减少 30% 的整体目标。退出结论：证据不足，保留规则版。重启试验所需材料是可核验的代码、权重、数据授权及按基础页面隔离的独立样本。

## R02：不安装 SST-Guard 扩展，不新增默认拦截

[SST-Guard 论文](https://arxiv.org/abs/2604.27497)提供第一方追踪分析思路。本轮对固定提交的扩展归档做静态检查：5,822,503 字节、42 个归档条目，未找到许可文件；扩展请求所有网址访问及 cookies、webRequest 等权限。没有执行归档或安装扩展。

作者真值 CSV 有 1,286 行，输出 CSV 有 403 行。这些是作者材料，既不是本计划 200 站观察集，也不是至少 50 站关键操作的独立实测。当前没有足够数据证明混合业务端点的误判率；不把信号分类直接升级为整站阻断。退出结论：证据不足，保留当前规则及有界观察，不声称新增追踪识别能力通过验收。

## R03：不将 PhishLang 接入默认硬拦截

[PhishLang 作者仓库](https://github.com/UTA-SPRLab/phishlang)的固定提交包含模型权重，但递归核对的 29 个路径中未找到许可证。没有下载或运行权重，也未取得独立的至少 10,000 个良性页及按时间、域名、模板隔离的恶意集。

固定 App 的本地 HTTP/IP/密码框夹具被当前钓鱼保护拦截，作为现有保护的负例保留。这不是模型准确率、召回率或文章裁剪通过证明。退出结论：证据不足，不新增学习式硬拦；不能用合成小样本替代每万次误拦统计。

## R04：有限测量结束，未覆盖范围保留

040在同一路径、同一签名App重新取得普通a/a/b、两个独立无痕会话和第三方iframe a/a/b，共8份实际读数。43项顶层断言与18项iframe/Worker断言通过，旧版本结果不混入当前分母。跨普通Profile再次遇到添加资料窗口无法读取，未创建新资料；正常退出重开后主App恢复。真实业务兼容性、过滤配置独特性和GPU计时侧信道没有测量。退出结论：本地有限结果保留，不提出消除指纹或新增默认拦截的建议。

以下为历史证据：

参考 [WGPULens](https://arxiv.org/abs/2606.26412)，在固定 Ver 2.0 (018) App 中，通过可见本地页面按钮取得五次记录：普通 a 站两次、普通 b 站、两个独立无痕会话。沿用项目原有探针，未关闭保护、修改 GPU 驱动或注入其他浏览器控制通道。

43 项本地断言通过：Canvas/Audio 同缓冲重复稳定，同站重复稳定，跨站、普通与无痕、独立无痕会话之间不同；WebGL 不公开调试硬件身份；WebGPU 在公开上限内可以创建设备，三类超限请求被拒绝。WebGPU 身份字段为空且上限为共同取值，不能据此宣称每个 Profile 有独立的 WebGPU 随机身份。

跨普通 Profile 测量在打开添加资料界面后遇到操作工具无法读取控件的问题，尚未取得结果。随后在023和026固定App分别通过第三方框架中的可见按钮完成a/a/b三次测量，各18项断言通过：Canvas及专用、共享、Service Worker在同一顶层分区稳定、不同顶层分区不同。真实业务站兼容性、过滤规则配置独特性和GPU计时侧信道仍未验证。这五次记录不能证明消除指纹，也不能代替 200/50 站兼容性要求。

旧诊断界面曾依据品牌字符串判断防护效果，现已修正为只呈现 API 读数与测量限制；026已在固定App实际打开新诊断界面并检查截图，文案明确配置开启不等于单页实测证明。

## R05：保留一个有界只读研究流程，不宣称学习收益

040已完成三页42/43/41比较、保存及重启回读、引用失效提示、真实42→47变化、相同内容去重、暂停跨到期和重启、删除的完整链。固定评测研究类24/24通过，属于当前实现的功能证据。另一次30配对请求试验只比较执行约束，输入减少24.33%，未达到30%目标；不是SCAFFOLD模板学习对照。退出结论：保留当前浏览器编写的有界流程，不引入训练框架或宣称学习收益。

以下为材料与历史证据：

重新读取的 [SCAFFOLD 论文](https://arxiv.org/abs/2609.05511)为 v1，提交于 2026-08-31；EMNLP 接收情况来自作者说明。作者仓库 LICENSE 引用 Apache 2.0，GitHub API 的 NOASSERTION 不等于没有许可证。没有引入其训练框架、运行 WebArena 环境或修改模型策略。

本地实现只复用一个由浏览器编写的多页读取流程，处于本计划最多三类任务、十个模板的上限内。018 固定 App 的三页研究读取 42/43/41 三个合成事实，整理请求只发送一次，三条引用均可打开。实际请求输入为 4,830 字节，结果与来源交叉核对通过。这是单次功能诊断，没有配对基线或收益置信区间，不能宣称论文复现或学习提升。

023已验证来源原文匹配、变更与不可用状态，以及无痕关闭后的会话清除。026已验证部分来源失败时保留可读事实、加密保存结果重启可读、研究转监控入口和监控暂停；027已取消测试监控，数据库回读为0条。各版本证据分列，未把历史结果混算为最终候选完整通过。完整 90 次任务与 100 个安全场景的分母不变。
