## 适配与修复

Quinn 的旧补丁编号与当前序列冲突，因此保留旧补丁的 Git 历史，在 Chromium 155 上导出 0274；0275 适配新增研究测试的列表接口，并在访问元素前检查列表存在和长度。0276 修复九来源测试的显式标签页预算，并以真实刷新代替带网址片段的同文档导航，检查旧观察失效。桌面最终为 276 个顶层补丁、506 项 overlay；V8 的独立补丁序列保持原有内容。

Agent 修复包括同步接管回执匹配、拒绝非预期接管回执、历史监控操作不干扰当前订阅、研究观察与真实来源的绑定。iOS 修复包括下载状态持久化、恢复数据与文件处理，以及恢复完成前的操作限制。

租约原型改为固定 SQL 查询；表计数只接受明确列出的表名，数据仍用参数绑定。增加未知表名和注入式表名的拒绝测试。发行脚本固定工具解析、参数数组、超时和无 shell 执行；已核对的固定调用使用局部安全说明，没有关闭扫描器或调整仓库保护规则。
