# Aegis 功能设置整合与迁移核对

日期：2026-10-20。状态：Ver 5.0 (218) 已完成本机 macOS 构建、固定证书签名及设置统一验收。实机发现的嵌入读写、下载默认值同步、模型参数回填和防护状态显示问题均已修复并复测。本次仅提交源码、回归测试和验收记录，不创建版本标签或正式 Release，不上传安装包。

## 目标

桌面设置侧栏只保留一个「Aegis 功能设置」，完整收纳现有自有功能设置。保留配置值、脚本授权、网站规则和旧链接；当前网站盾牌、阅读器、助手任务操作继续提供快捷操作。

摘要与助手的基础模型连接原本共用 `AegisService::SetModelSettings` 和 `aegis.model_*` 配置；本次保留该关系，并在页面中提示保存任一模型表单会更新共用连接。模型池、路由和 TypeSafe 密钥仍单独管理。两处原表单均保留：摘要表单支持清除连接密钥，助手表单支持把未保存的候选模型加入模型池。所有配置继续通过原接口保存，本次没有进行存储格式迁移，也没有重置默认值。

## 入口兼容

- `chrome://settings/aegis`：唯一设置首页。
- 原四个设置地址 `/aegisEnhancements`、`/aegisReading`、`/aegisGestures`、`/aegisPrivacy` 继续可访问，侧栏均归属 Aegis 功能设置。
- 原「隐私与安全」页面的 Aegis 位置保留为统一设置快捷入口。
- 桌面 `chrome://aegis/` 导向统一首页；旧下载等已知片段导向对应分类。
- 独立脚本和手势设置地址导向新分类，并保留查询与片段参数，避免丢失盾牌传入的标签页或脚本定位。
- Markdown 阅读器属于内容操作页面，继续保留原地址。
- 桌面助手侧栏的全局配置改为统一设置入口；首次尚未连接模型时，入口明确提示连接模型。

## 实现与数据边界

原防护中心和助手中的完整控件由设置页面复用，保留原生保存逻辑及既有配置关系。内部页面只允许 `chrome://settings` 嵌入。布局消息仅接收当前子页面、准确来源和有限高度。旧防护子框架没有 Chromium 的 chrome.send 绑定，现由父设置页校验当前窗口、精确来源、请求编号、固定接口及参数类型后转发原接口；拒绝其他来源和任意命令。助手继续使用原 Mojo 接口。

本机语言包使用助手来源下的 IndexedDB。为避免嵌入设置后出现新的第三方存储分区，仅让 `chrome-untrusted://aegis-agent` 延续原有第一方存储键；普通网页及其他内部来源不扩大豁免。

本次修改针对桌面设置。Android 版本元数据按仓库契约同步；未以此宣称完成 Android 或 iOS 构建验收。

## 修复的保存与回读问题

- 原防护页面嵌入后缺少原生消息通道：增加只允许当前受信任子页使用的固定接口桥。初始化、保存失败和超时均能显示错误。
- 原下载页的七项全局设置遗漏：在「下载增强」复用原组件，保存请求串行处理，收到后台结果后显示成功；限速小数规范为整数。修改全局参数后，同页预览的新任务会重新取得最新默认值。
- 摘要保存共用模型后，助手表单仍显示旧值：未编辑的表单同步后台最新连接，保留尚未保存的草稿和密钥输入。
- 模型池高级参数没有回填：按当前连接匹配原条目，回填质量、延迟、费用、推理档位、价格和能力；明确路由自动保存、高级参数通过加入池保存。
- CNAME 防护在跟踪器关闭时显示为关闭，混淆设置与运行依赖：分别返回已保存值和实际运行状态，界面保留用户选择，并说明需要同时开启跟踪器拦截。
- 新手势设置页的练习范围判断遗漏：新旧设置地址共用地址判断，练习区域继续阻止真实动作。
