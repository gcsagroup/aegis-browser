# Aegis 八类设置全面审查与交互改进方案

日期：2026-10-21。审查基线：Ver 5.0 (223)，源码提交 `b29212cd953931a406c4572c3f8934320f566615`。

状态：八类设置整改、语言包扩充与本轮可执行统一验收已完成，交付 Ver 6.0 (242) 本机测试版。[实施与验收报告](settings-overhaul-acceptance-2026-10-21.zh-CN.md)列明结果、未覆盖项目及翻译质量限制。正式发布不在本轮范围内。下文“本次审查证据”保留的是 Ver 5.0 (223) 审查时的历史基线。

## 1. 结论与完成标准

当前主要问题是页面职责和操作流程没有理顺：统计、工作区、任务操作和长期设置混排；功能虽然存在，用户却缺少清楚的入口和下一步；同一设置还可能由多处表单编辑。继续增加卡片或折叠区域不能解决这些问题。

推荐保留八个设置分类，重新整理每页内容。设置负责默认行为、权限策略和必要的配置状态；阅读、脚本编写、下载任务、网页摘要在各自工作区完成；浏览统计和事件记录进入防护详情。复用现有功能和数据，不为此次整理另建一个大而全的管理中心。

完成标准：用户能找到设置、理解作用范围、完成操作、看懂结果、失败后继续；移出的功能依然可达；保存与重启一致；长列表、窄窗口、缩放、键盘使用不遮挡、不丢输入。以下同时列出功能去向、具体交互和验收条件。

“阅读下面的两块没用”需要分别处理：

- **Markdown 自动预览有实际功能。** 原生导航逻辑会检查已授权来源及 Markdown 响应，阅读器来源菜单也能保存授权。问题是设置页没有添加入口，且只显示已启用项；关闭后重新进入页面，该来源被过滤掉，无法从此处重新开启。应补全管理流程。
- **图片权限这一卡片目前确实不是设置。** 它只有说明文字；实际的“加载／停用外部图片”和“选择本地图片目录”在文档菜单内。应移除空卡片，把说明放在需要授权的位置。现有实现是默认不加载外部图片、用户按需点击加载，并非每次自动弹出询问；文案也应改准确。
- **默认阅读外观有保存和应用逻辑。** 设置页保存后下次打开文档应用，阅读器自身调整则可立即应用。应把两个作用范围说明清楚，并增加本页预览，不能将它归为无效功能。

| 实验功能 | 每项用途、开关、可用性、限制与使用入口 | 实际段落分析和结果展示 | “前往阅读工作区使用”，不在设置自动运行 |

必要的状态仍保留：规则是否更新成功、语言包是否可用、本机工具是否启动、模型连接是否已配置，直接影响设置是否生效。它们与“本次拦截多少请求”等浏览统计不同。

导航要求：

1. 首页八行统一高度、图标和简短描述；描述随归属一起修改，不再宣传设置页内有防护记录、阅读库或图片权限开关。
2. 每页只有一个标题、一句必要说明和一致的返回位置；不再套入另一套带重复标题的独立页面外壳。
3. 普通下载目录等既有 Chromium 设置保持原归属，通过链接相互到达，不复制同一个开关。
4. 移出前先完成目标页面。旧 URL、盾牌链接、浏览器菜单、侧栏入口和书签均需迁移；保留网页／脚本定位参数。当前旧入口会重定向回设置，不能只加一个链接就声称完成迁移。
5. 搜索命中具体设置行并定位；必要时只展开匹配区域。迁出的操作给出“前往对应工作区”的结果，不因旧关键词继续整页展示统计或任务。

## 4. 隐私与防护

### 已确认的问题

实机首屏首先展示防护概览和浏览记录，真正开关在其后。指纹自检埋在技术详情里。“网站例外与权限”实际只提供浏览器网站权限链接和临时暂停说明，并不是 Aegis 例外管理列表。

### 建议页面

- **网页防护**：跟踪器拦截、钓鱼防护、指纹防护、挖矿检测。挖矿保留“仅观察”，不能用总状态暗示会阻断。
- **跟踪清理**：链接参数、Cookie、伪装跟踪、跳转跟踪。每项保留一句直接效果说明，更多原理放帮助。
- **本地隐私处理**：说明影响可疑网址分析、脱敏和摘要准备；相关依赖不可只用笼统总开关解释。
- **过滤规则**：自动更新、最后成功更新时间、更新状态及“检查更新”。规则数量放详细信息，不占主层级。
- **网站权限入口**：明确区分 Chromium 网站权限、Aegis 防护例外和临时暂停。没有对应持久化能力时，只提供准确入口，不做一个虚假的空管理器。

开关保存后就地显示结果和生效时机。伪装跟踪已开启但跟踪器拦截关闭时，显示“已保存，当前未生效：需要开启跟踪器拦截”，提供跳转；不偷偷替用户打开依赖。需要刷新网页的项目给出“刷新后生效”，刷新动作要指向明确网页。

过滤更新失败时保留现有可用规则和最后成功时间，错误出现在更新按钮旁；下载中避免重复更新。统计迁移时保持“本次浏览”的原口径，不擅自变成长期累计，也不将零记录当作网站安全证明。

验收：无浏览统计或事件列表；逐个开关的保存、依赖和实际状态相符；更新成功、失败、离线均可理解；盾牌与新详情页可到达，旧深链接不会回到错误分类。

## 5. 网站增强与脚本

### 已确认的问题

网页选择器、脚本列表、网站规则、运行详情和恢复操作处于同一页面。无网页时顶部提示用户去另一个标签打开网页，但导入、编辑和删除已有脚本不需要目标网页。网站规则和规则编辑连续折叠；“草稿或停用”把两种状态混为一谈；源码编辑区同时给出多个平级按钮。

### 设置页

网站规则默认展示，每行包含网站、已启用能力、是否暂停，以及“编辑／移除”。提供明确的“添加网站”，空状态也保留该按钮；支持搜索已有规则。

添加规则时可以输入地址，或选择已经打开的网站。保存前显示标准化后的来源，例如 `https://example.com`，让用户知道路径不会限定规则。右键、复制为主要选项；子域名、调试兼容放高级区域。继承父域规则时明确显示继承来源，修改前说明正在改父域还是当前网站。

保存成功后原位置更新，并说明重新加载后生效；目标网页已关闭也能保存规则。移除规则提供短时撤销，或明确确认，不默默刷新网页。脚本部分只留“管理用户脚本”的入口及简短说明。

### 脚本管理器

| 使用阶段 | 主要内容和操作 |
| --- | --- |
| 列表 | 搜索脚本、状态筛选、名称、适用网站、编辑／启停；新建和导入始终可用 |
| 创建 | “手动编写”和“AI 编写”分开；AI 不可用时可以手动继续，并链接到模型设置 |
| 编辑 | 源码、匹配网址与权限摘要；主要操作为“保存草稿”“试运行”“启用”，导出和回退放更多操作 |
| 试运行 | 此时才选择目标网页；显示网站和适用性，拒绝不匹配或已经失效的目标；结果紧邻试运行按钮 |
| 启用 | 区分保存草稿、授权启用和网页已执行；启用后说明下次页面加载生效，不冒充立即执行成功 |
| 运行详情 | 随所选网页显示匹配脚本、等待刷新／执行中／已执行／失败及错误；不替换全局脚本列表 |
| 恢复 | 高级区域内写明影响全部脚本还是本站，以及是否重载；执行前列清范围 |

空态应说明下一步，不用大面积空白占位。目标选择显示标题和域名，长地址可查看完整内容。打开来源、保存脚本、切换目标等操作不能悄悄覆盖未保存源码或规则草稿；后台刷新保留用户输入。

验收：没有网页也可导入和编辑；试运行时才要求目标；规则可新增、编辑、暂停、恢复；脚本草稿、停用、启用待刷新与实际执行状态可区分；改源码撤销旧授权的现有规则保留；私密会话隔离仍有效。

## 6. 阅读与 Markdown

### 默认阅读外观

把外观放在首屏。五个控件旁显示固定样本文档，包含标题、中文、英文、代码块、列表和链接，调整后立即预览。预览只使用内置文本，不读取用户文件，不加载外部图片。

字号显示单位与允许范围；输入非法值在字段旁提示，不能显示保存成功。主题、字体、字号、行距、宽度自动保存；提示“作为新打开文档的默认外观”。不直接改已打开的其他文档；阅读器内调整仍说明当前显示效果及是否更新默认值。

提供“恢复默认外观”，范围仅为五项外观。保存失败时保留尝试值供重试，明确尚未生效；连续快速修改按最后一次意图落盘，防止旧回包覆盖新值。

### Markdown 自动预览

改成可操作的“自动预览网站”列表：网站来源、开启状态、移除；保留关闭项，重新进入页面仍能再次开启。列表提供“添加网站”和搜索。

允许粘贴网页地址，提交前转换并展示协议、域名和端口；路径不作为匹配条件，子域名不自动继承。只接受普通 HTTP／HTTPS 来源，拒绝无效地址和带账号密码的地址；重复项定位现有行。文档的来源菜单与设置页修改同一份配置。

空态文案：“尚未添加网站。添加后，来自该网站的 Markdown 原文会自动进入阅读器。”同时显示添加按钮，并说明普通 HTML 网页不会因此自动转成 Markdown。

开启／停用影响下一次访问，不强制跳转当前文档。移除与停用区分：停用保留条目；移除删除授权记录。现有存储只提供启停，真正移除需要补充对应操作，不能只在界面隐藏。

### 阅读库与图片

阅读库列表、刷新和原文展开从设置移出，接入现有阅读工作区。设置仅留一行“打开阅读工作区”；文档列表数量不再影响设置高度。已有记录、归档状态、来源和原文均保留，不复制数据创建第二个阅读库。

图片权限卡片删除。遇到未加载图片时，在文档内显示原因及“加载外部图片／选择本地目录”。外部图片只对当前打开的文档授权；本地目录只用于该文档资源。明确停用只阻止后续加载，不能撤回已经发出的网络请求。默认外观、自动预览网站和图片授权互不联动，不新增“永久允许所有图片”的总开关。

### 本机翻译语言包

**补充审查：当前语言覆盖确实不足，不能只迁移现有两个下载按钮。** 界面、阅读工作区方向列表和翻译 Worker 均只接入英语与简体中文的两个单向包；固定下载清单也只有这两个方向，并不存在被隐藏的其他语言包。

| 当前方向 | 下载大小 | 解压模型文件大小 | 当前覆盖边界 |
| --- | --- | --- | --- |
| 英语 → 简体中文 | 36.13 MB | 51.93 MB | 仅此方向 |
| 简体中文 → 英语 | 47.60 MB | 70.08 MB | 反向需要单独下载 |

以上为清单文件字节数按十进制换算；实际安装还包含存储开销及下载、校验期间的临时空间。界面支持简体、繁体和英文，不代表翻译模型支持相同范围；繁简转换也不能直接冒充独立翻译模型。

推荐将本机翻译放在阅读分类，建立“可下载语言包／已安装语言包”管理界面：

1. 可以按源语言和目标语言搜索，常用目标语言独立设置。自动识别原文后，只有检测到已支持的方向才能直接执行；不支持时明确说明缺哪个方向或暂未提供。
2. 每项显示翻译方向、下载大小、安装空间、版本、来源及未下载／下载中／校验中／可用／失败／可更新状态。提供下载、取消、重试、更新和移除；下载完成且校验通过后才标记可用。
3. 需要双向时支持一次选择两个包；批量下载显示总大小和所需空间，排队执行并分别报告结果。安装失败保留原可用版本；移除时说明会失去哪个离线方向。
4. 语言包管理与正文翻译分开显示进度；切换方向不能把另一个包的进度显示过来。缺包时从阅读器直接定位到所需包，安装后可返回原文继续，不丢批注。

语言扩充建议按用户阅读场景安排候选：先评估日语、韩语与中文的互译需求，再评估法语、德语、西班牙语、俄语等。**这些是拟评估范围，不是已确认有可直接接入的兼容包。** 每个方向必须先确认模型来源、许可、Bergamot 兼容性、大小和实际质量，再进入可下载目录，不能只往下拉框增加语言名称。

有直接模型时优先直接翻译。若只能通过英语中转，应明确标注“经英语中转”、列出需要下载的两个方向及总大小，并单独测试误译与延迟；不能把“日语 → 英语”和“英语 → 中文”自动宣传为已验证的日中直译。未支持的组合不静默改用外部服务。

实施时将语言目录作为界面、下载校验和运行时的共同依据，替换目前多处写死的方向列表；目录只暴露通过兼容性及质量检查的组合。现有中英模型也存在已记录的语义质量问题，新包不能只以“能下载、能输出文字”为通过标准。

扩充验收必须覆盖每个新增方向：真实下载与校验、取消／断网／空间不足、离线使用、重启回读、更新失败回退，以及否定句、数字日期、短标题、长文漏译和代码链接保留。中转方向另测两阶段的累计误差。该段为实施前验收要求；本轮已扩充并下载校验模型，开放方向与逐项覆盖范围见[实施与验收报告](settings-overhaul-acceptance-2026-10-21.zh-CN.md)，未把所有故障场景一概记为原生实测通过。

验收：默认外观实际应用于新文档；快速修改和非法字号正确处理；来源可添加、关闭、重新进入后开启及移除；Markdown 与普通 HTML 行为不同；打开另一个文档后图片授权重置；已有阅读记录和语言包不丢失。

## 7. 鼠标手势

### 先修布局

当前独立页样式使用 `:root` 定义背景等变量，嵌入设置的 Shadow DOM 后不能按原方式命中；保存栏又使用该背景变量并固定在底部。这是透明覆盖问题的直接代码依据。应使用设置容器自己的变量和组件样式，统一浅深色、间距、焦点及滚动规则。

推荐取消整页悬浮保存栏，使用分组和条目就地保存。用户不必拉到页尾保存一条新手势；不以增加不透明背景作为完整修复。

### 绘制即添加

“先试一试”改成“绘制并设置手势”。练习区域始终不执行真实浏览器动作。

| 绘制结果 | 展示 | 可执行操作 |
| --- | --- | --- |
| 有效、尚未绑定 | 方向箭头和“尚未绑定” | 选择动作 → 添加并保存；重画 |
| 已绑定 | 方向箭头和已有动作 | 修改绑定；查看所在行；重画 |
| 无效或过长 | 具体原因 | 重画；添加禁用 |
| Esc、失焦或取消 | 已取消 | 清除可提交结果，不复用上次轨迹 |
| 保存失败 | 保留方向、动作和失败原因 | 重试；取消本次编辑 |

新动作必须由用户主动选择，不默认填“后退”或“关闭当前标签”。按导航、标签页、页面、PDF 分组；PDF 动作标记适用范围。提供方向按钮和键盘操作作为替代输入，字母编辑保留在高级方式中。

基本开关自动保存，识别距离在滑动结束或键盘调整提交后保存；预览应明确使用当前尝试值。已有绑定默认显示箭头与动作，点“编辑”才出现编辑控件；重复方向在当前行立即提示。每条编辑有保存和取消，移除有撤销。

网站例外改成域名列表和“添加网站”，支持粘贴 URL 后展示提取出的域名；保留现有子域名需单独添加的规则。批量文本编辑可保留为高级入口，不改变既有匹配含义。

“恢复默认”先明确范围：基本选项、绑定、网站例外分别处理；恢复全部需清楚列出会覆盖什么。当前按钮直接恢复并保存全配置，应更改。

### 保存边界

“添加并保存”只保存当前新增绑定，不偷偷提交其他组的草稿。如果继续使用现有完整配置接口，应基于最近已保存值合并当前组更改，串行提交；其他组草稿留在界面。保存回包不覆盖等待期间的新输入；多个设置标签同时编辑时检测冲突并提示重新读取，不能用陈旧快照覆盖新配置。

验收：实画新方向并保存，重启后普通网页动作生效；已有方向修改后只有一条；练习关闭标签动作不关闭页面；取消、失焦、模糊方向、长度超限不复用旧轨迹；失败可重试；64 条上限清楚；恢复与撤销范围准确；窄窗及缩放无任何按钮覆盖内容。

## 8. AI 与模型

### 已确认的问题

同一页上方“摘要与模型设置”和下方“AI 模型”各有协议、地址、模型和密钥输入及保存按钮。它们编辑共用基础连接，目前需要文字解释互相影响。模型池的质量、延迟、费用、推理档位等集中在高级区域，缺少明确的条目编辑流程；部分主界面用 `Q0 / L0` 等表达，不利于理解。

### 推荐结构

1. **功能开关**：AI 助手、网页摘要，各自说明作用。进入设置不读取或发送网页内容；“摘要当前标签页”移到页面操作。可保留“打开 AI 助手”的轻量入口。
2. **共用模型连接**：一份协议、服务地址、密钥状态、模型选择；“获取模型列表”和“保存连接”。明确摘要与助手默认连接共用。
3. **模型池与选择方式**：固定模型、均衡、质量优先、费用优先、仅本机；显示当前选择方式。每个模型提供编辑／移除，当前条目明确高亮。
4. **高级模型能力**：打开具体模型才编辑质量、延迟、价格、能力与推理档位，不与基础连接保存混用。
5. **TypeSafe 目标判断**：独立服务和密钥，保留发送目标的说明；开关、密钥与保存范围清楚，不能让“主模型在本机”掩盖该外部调用。

模型字段细节：

- 地址格式、协议路径与模型 ID 在对应字段报错；保留手动模型 ID，不强迫服务支持模型列表接口。
- 获取列表说明请求哪个地址，只用于连接发现，不自动发送页面或启动推理。失败区分地址不可达、鉴权失败、服务不支持列举、返回空列表，并保留手动输入。
- 密钥留空表示保留已保存值；“未配置”“已保存”“本次待替换”分清。清除是独立动作，不能把空输入当清除；更换地址时不自动将旧密钥发送给新服务。
- “保存默认连接”“添加模型”“保存该模型修改”各有明确语义，不再让用户猜添加是否覆盖默认模型。
- 价格写明币种、计费单位和用途，未知显示“未填写”，不能显示为零费用。质量和延迟说明是用户提供的评分还是实际测量值；不要暗示系统已经测试。
- 推理强度和长度尽量拆成有标签的字段，保留原支持值，避免主要流程要求输入 `medium:8192`。
- 路由没有可用候选时说明原因；“仅本机”不能静默回退外部服务。移除当前默认或唯一可用模型前说明影响并要求选择替代项或明确停用。

验收：页面只有一份基础连接；摘要和助手回读一致；模型池独立编辑不改变未提交连接；密钥保留、替换、清除和地址切换边界正确；列表获取失败仍能手动配置；路由无候选、未知价格与仅本机约束都有可理解状态。

## 9. 下载增强

实机前半页是默认策略，后半页又包含“下载中心／新建下载／下载记录”。推荐移出完整任务面板，只保留“打开下载中心”。目标下载中心必须实际承载镜像、种子和磁力操作，不能仅链接普通记录页而丢掉新建能力。

设置分两组：HTTP(S) 并行策略，以及种子／磁力新任务默认值。前者说明不支持分段时退回单连接；网络、电池和过热策略区分可调整偏好与固定行为。后者写明仅影响新任务，正在下载的任务不悄悄变更。

限速字段推荐直接显示“不限速／自定义”，自定义时显示数值和 KiB/s；界面换算可以辅助，但落盘单位保持一致。负数、空值、过大数值就地提示。DHT／PEX 保留名称，并解释为节点发现方式；“完成后停止上传”如果是固定行为，就用说明表达，不做假开关。

验收：七项默认设置保存重启一致；新建任务继承最新值，临时修改不反写默认；已有任务不受默认修改影响；镜像、磁力、种子和普通下载从下载中心全部可达；无不必要的新任务自动创建。

## 10. 本机工具连接

本页规模小，可以保持简单。主层级使用“允许本机工具连接”，配一段准确的能力说明；设置偏好和实际运行状态分开，显示已关闭／启动中／等待连接／已连接／因无痕窗口暂停／启动失败。

连接可用时直接提供地址和复制按钮，示例代码放“连接方法”，避免用户只能在技术详情中寻找关键地址。不可用时说明原因，不提供看似有效的旧地址。开启失败不能永久停在“正在准备”，应给重试或诊断入口。

保留只对本机开放、普通网页内容不会自动脱敏的既有边界；不增加远程监听或新的授权范围。关闭后须核对实际端点停止，并在连接中断后更新状态。客户端数量仅在底层能可靠提供时显示，不编造连接应用的身份或名称。

验收：偏好已开启但端点未启动、无痕暂停、无客户端、真实客户端连接和关闭均正确区分；复制入口只在有效时可用。本次审查没有开启此功能，以上运行场景需实施时专门验证。

## 11. 实验功能

现页只有合并说明与两个开关，用户不知道开启后去哪里使用。拆为 MINIM、PhishLang 两个简洁条目，分别说明分析什么、是否开启、资源是否可用以及“前往阅读工作区使用”。

开关表示允许手动使用，不能呈现为自动扫描、自动拦截或正在防护。资源状态必须来自实际检查；缺失时说明获取方式或当前不支持，不能仅根据开关写“已就绪”。不为首次打开设置自动下载或运行模型。

限制说明紧邻对应功能，保留现有评测问题与不会删改正文、不会拦截网页的边界。关闭时保留已有结果，不把停用解释为清空；若已有任务运行，说明如何取消，不默默丢结果。

验收：默认关闭、重启回读一致；开启不下载、不推理；进入正确的阅读分析入口；资源缺失、关闭与就绪可区分；实验开关不再出现在 AI 或普通防护设置中。

## 12. 所有页面共用的交互规则

| 状态或操作 | 统一行为 |
| --- | --- |
| 首次加载 | 显示正在读取；未读到配置时不可编辑假默认值；失败就地重试 |
| 即时设置 | “保存中 → 已保存／失败”，只在收到后台成功后称已保存；失败清楚显示当前实际值 |
| 复合表单 | 本组明确保存和取消，脏状态可见；离开时处理草稿，不静默丢失 |
| 保存并发 | 按组串行或合并最后意图；旧响应不覆盖新输入；重复点击不重复创建 |
| 错误位置 | 字段错误在字段旁，操作错误在按钮附近；提供具体恢复方式，不只在页顶输出原始异常 |
| 后台状态刷新 | 更新运行状态，保留正在编辑的草稿和焦点；不得把输入框突然改回已保存值 |
| 成功反馈 | 写明已保存什么、何时生效；可温和消退，失败信息保留到用户处理 |
| 空列表 | 一句话解释，加一个可用的主要行动；无权限或读取失败不能冒充空列表 |
| 禁用控件 | 附上原因与解决入口，不仅变灰；可继续完成不依赖该条件的操作 |
| 删除／恢复默认 | 写清对象和范围，优先支持撤销；不影响其他分类、密钥、文件或用户数据 |
| 多页面修改 | 用实际最新状态或版本检查处理冲突，不将整页旧快照写回覆盖其他页修改 |

布局与可访问性要求：

- 主内容只使用一个页面滚动区域；展开、错误提示、语言切换后高度正确，不出现截断或大段空白。
- 表单宽度按内容设置，地址可以较宽、字号和限速较窄；开关、复选框不继承普通输入框宽度。页面留白和卡片层级一致，避免一项设置套三层容器。
- 900 CSS 像素窗口、较窄有效视口和 125%／150% 缩放下，按钮换行而非覆盖；长域名、模型名、脚本名可换行或展开查看。
- Tab 顺序和视觉顺序一致，有明显焦点；保存后焦点留在相关位置。弹窗可用 Esc 取消，关闭后焦点返回触发按钮。
- 状态使用可读文本并向辅助技术播报，不能只靠颜色；箭头同时提供方向名称；绘制操作有键盘替代。
- 简体、繁体和英文逐项检查，动态状态、错误及按钮不能遗漏。首次加载不短暂露出整套助手工作区或空白按钮。
