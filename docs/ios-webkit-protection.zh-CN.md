# iOS Ver 5.0 网页保护

适用 iPhone、iPad，最低 iOS 18.4。保护通过系统 WebKit、本地规则和页面结构检查实现。当前为开发候选；完整验证结果见[验收记录](audit/ios-webkit-protection-2026-10-12.zh-CN.md)，四端差异见[功能清单](platform-features.zh-CN.md)。

## 开启与恢复

在“更多 → 设置 → 保护选项”中管理高风险网址、已知挖矿资源、已知指纹资源、系统加固和严格指纹限制。挖矿及指纹资源默认开启，独立于广告过滤；暂停广告过滤不会关闭这些规则。

- **风险页面**：本地已知钓鱼主机或多项高风险信号会打开原生阻止页。结构检查发现风险后替换并卸载网页。可返回起始页，或允许当前标签访问同一完整网址 10 分钟；改换网址即撤销该允许，其他标签和私密窗口不共享。
- **资源误拦**：页面“更多”菜单可临时允许本站安全资源 10 分钟，也可立即恢复拦截。该操作同时暂停本标签当前来源的挖矿与指纹资源规则，不放开钓鱼导航检查。已加载脚本不会因恢复规则而自动撤回。
- **系统加固**：默认关闭。iOS 26.4 以上使用公开安全限制，关闭网页 JIT；MTE 效果取决于设备。旧系统显示默认 WebKit 保护，不冒充同等加固。始终保留系统 Lockdown。网站设置可指定单站选项，重载后生效。
- **严格指纹限制**：实验功能，默认关闭。限制 Canvas 像素、WebGL 读取和音频结果，可能影响正常导出、游戏和音频。在“网站设置与权限”中选择“恢复兼容”，再重新载入。

系统欺诈警告和已知主机 HTTPS 升级始终启用；HTTPS 失败采用系统的用户决定回退策略。应用不替用户绕过系统警告。

## 本地检查读取什么

导航前检查完整主机规则和网址风险。注册域依据包含私有后缀的 Public Suffix List，并按系统 URL 处理国际化域名；共享托管的不同租户不合并为同站。

页面提交后，在隔离脚本世界立即读取有限标题、密码框数量、相关表单目的来源和 iframe 来源，之后每两秒检查一次，最多一分钟。不开启模型请求，不读取输入值、密码、验证码或正文。正常跨站登录、单个国际化域名或普通绘图不单独作为封禁理由。同一文档切换站内路径后，仍在原观察窗口内按当前网址检查。导航、停止或关闭标签会使旧检查失效；新文档不会沿用前页提示。

另一个页面脚本只记录 Canvas、WebGL、Audio、Worker、WASM 的调用类别和有限次数。页面可以伪造这些信号，因此它们只提供提示，不会触发任意原生操作或自动判定未知挖矿。

## 规则来源与更新

内置版本 `2026101201`：190,191 个精确钓鱼主机、312 个挖矿主机、4 个明确指纹采集端点。完整来源、摘要与许可见 [security-rules-sources.json](../apps/ios/BrowserKit/Resources/security-rules-sources.json)。

- [Block List Project](https://github.com/blocklistproject/Lists)：钓鱼主机，仓库 Unlicense；列表旧头仍标 MIT，保留原始来源信息。上游列表标注最后更新为 **2026-07-06**，不能作为实时活跃钓鱼判断。
- [NoCoin](https://github.com/hoshsadiq/adblock-nocoin-list)：已知浏览器挖矿主机，MIT。
- [EasyPrivacy](https://easylist.to/pages/licence.html)：选择明确采集端点，沿用本项目已选的 CC BY-SA 3.0 规则数据许可。
- [Public Suffix List](https://publicsuffix.org/list/)：MPL 2.0，保留源文件许可头。

规则包使用 Ed25519 验签，限制大小、域名格式、条目数、版本及有效期。此版**随 App 更新规则，不提供在线安全规则订阅服务**；广告过滤的自动更新开关只控制 EasyList/EasyPrivacy。内置包过期后继续使用并提示更新 App。签名不能证明上游每个域名仍然恶意，也不能替代维护和误报处理。

## 已知边界

结构检查发生在页面开始加载之后，不能保证此前没有请求或数据发送；一分钟之后新出现的表单不在本轮结构观察窗口内。未知 fetch、XHR、WebSocket 外传、脚本 CPU 消耗和任意 HTTPS 响应正文没有被完整检查。

严格指纹限制属于页面 API 包装器：Worker、OffscreenCanvas、缓存函数及页面恢复原函数可能绕过。默认保留 WebKit 自身隐私能力，没有公开接口可以完整等同 Safari 的高级指纹保护。V8 字节码模块和完整 DNS/CNAME 检查没有移植到 iOS。

模拟器可验证导航、资源阻断和界面，不能证明真机 MTE、耗电、真实攻击检测率或正式发行资格。
