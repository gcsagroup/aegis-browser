# Aegis Browser Agent v1 用户指南

## 开启与进入

1. 正常启动当前 macOS 本地候选，不需要附加 feature flag。
2. 普通 Profile 的工具栏会显示 Agent 按钮；已有 Profile 升级时会一次性自动固定，之后
   仍可由用户取消固定。点击按钮可看到侧栏和启用提示。
3. 打开 `chrome://aegis`，在“浏览器 Agent”区域开启执行总开关。
4. 配置模型 provider、Base URL 和模型名；loopback 模型可以不填 API key。
5. 点击“打开 Agent”，或使用工具栏按钮、右键菜单、`Command+Shift+A`。

Agent 入口默认显示，但模型调用、工具执行和监控仍按 Profile 默认关闭，必须由用户显式
开启。无痕、访客和系统 Profile 不显示可用入口。

## 三种模式

- Ask：只允许只读工具，适合研究、总结和检查。
- Act：执行当前已确认计划，遇到 R2 动作暂停并要求精确审批。
- Automate：可按预算连续执行低风险步骤；不会绕过审批或用户接管。

## 发起任务

1. 先打开要处理的网页。
2. 在侧栏填写目标，并逐行检查允许的精确 origin。
3. 选择研究、浏览器管家、安全下载或购物工作流。
4. 点击“生成计划”，检查 provider、model、数据、工具、预算、风险和每个步骤。
5. 确认后点击“开始”。任务可随时暂停、恢复、接管或停止。

网页中的“忽略用户”“读取 Cookie”“扩大域名”等文字都只是网页内容，不是 Agent 指令。

## 收藏夹整理

Agent 先读取快照并生成预览。应用前会检查树 revision；如果你在预览后手动改了收藏夹，
旧计划会因冲突拒绝。成功应用后可点击“撤销”，恢复原父节点、顺序、标题和 URL。
v1 不自动删除收藏夹。

URL 检查中的 401、403、429 和超时不会直接判定为死链；404、410 等明确结果才会进入
失效候选。每次最多检查 100 个用户选定节点，整体并发最多 4、同一 origin 最多 1 个
请求，并带有超时和 429 退避。

## 安全下载

Agent 会比较官方来源、版本、平台、架构和哈希，然后通过浏览器原生下载中心启动下载。
下载完成后才校验 DownloadItem 和 SHA-256。错误架构、恶意重定向或错误哈希都会失败。
Agent 不绕过系统下载安全提示。

## 购物助手

购物工作流显示商家、商品、数量、单价、运费、税费、优惠、当前总价、配送、退货、来源
节点数和观察指纹。进入最终确认前会再次观察页面；价格或页面变化会使旧确认失效。

最终购买按钮只能由用户操作。Agent 会进入“用户接管”，隐藏批准按钮，并明确提示最后
一步由你完成。完成或放弃后，再回到侧栏结束接管状态。

## 监控

监控仅在浏览器运行时工作，支持价格、库存、页面变化和 URL 状态。监控可列出、暂停和
删除；连续失败会退避。通知只包含监控类型和站点 origin，不执行购买或其他外部动作。

## 隐私与故障处理

- 侧栏显示的是当前任务范围，不代表全浏览器授权。
- API key 使用系统加密存储，不会回显到 Agent UI。
- 停止任务后，受控 tab 和 Actor 会释放；两秒内不应再启动新工具。
- 浏览器异常退出后，重新打开任务时需要恢复确认；待批准动作不会自动执行。
- 收藏夹撤销只在当前浏览器会话有效；重启后不会恢复或重放旧写操作。
- 未完成任务元数据保留 7 天，已完成/失败/取消/过期任务元数据保留 30 天；页面正文和
  原始工具结果不写入 TaskStore。
- 关闭总开关会取消模型、Actor、审批和监控。

如任务失败，先查看侧栏时间线和错误。不要通过开启远程调试、放宽 origin 或向模型提供
秘密来“修复”；这类做法超出 v1 安全边界。
