# iOS Ver 4.0 使用說明

本輪補齊瀏覽設置、閱讀資料和有限瀏覽器操作，繼續使用 SwiftUI 與系統 WebKit。四端差異見[功能對照清單](platform-features.zh-TW.md)；測試範圍見[驗收記錄](audit/ios-portable-features-2026-10-11.zh-CN.md)。這仍是開發候選，模擬器結果不代表真機、App Store 或四端正式發行驗收。

目前候選為 **Ver 4.0 (82)**。先前三批功能的完整與修復複測見原驗收記錄；新增搜尋引擎刪除已通過雙端相關回歸及實際操作，詳見[搜尋引擎驗收（簡體中文）](audit/ios-search-engines-2026-10-11.zh-CN.md)。

## 搜索、主頁與瀏覽設置

打開 **更多 → 設置 → 搜索、主頁與瀏覽方式**。選擇 DuckDuckGo、Google、Bing、百度或自定義搜索，然後點擊 **保存瀏覽設置**。自定義模板必須使用 HTTPS，查詢參數中恰好包含一次 `{searchTerms}`，例如 `https://www.google.com/search?q={searchTerms}`。搜索文字按查詢參數編碼，不會作為網址結構執行。

展開 **管理搜尋引擎**，點選引擎旁的刪除按鈕，可刪除預設引擎或自訂項目。刪除目前預設引擎會切換至剩餘的第一個；全部刪除後不再將網址列文字傳送至搜尋服務，但仍可直接開啟網址。點選 **恢復預設引擎** 可恢復清單，原自訂範本保留。以上變更均在點選 **儲存瀏覽設定** 後生效，重新啟動後維持。

在同一頁面設置主頁和啓動方式：恢復普通標籤、打開起始頁或主頁。啓動方式在新建瀏覽窗口時應用；勾選“新標籤使用主頁”後，新標籤加載主頁。私密標籤不跨啓動恢復。

網頁顯示包含默認縮放、桌面網站、JavaScript、腳本彈窗和媒體播放選項。網站專用規則優先；JavaScript 與桌面模式在重新載入後生效，彈窗與媒體規則用於新標籤。關閉歷史記錄只停止添加新記錄；清除已有記錄請使用隱私設置。

## 網站與保護

- **設置 → 網站設置與權限**：選擇當前網站或已保存網站，設置縮放、移動/桌面模式、JavaScript、相機和麥克風。規則按協議、主機和端口隔離。相機與麥克風只提供“詢問”和“阻止”，仍需系統許可。最多保存 200 個網站。
- **設置 → 網站數據管理**：選擇網站並確認清除。為避免頁面重新寫入，清除前會關閉全部窗口的普通標籤；私密標籤、收藏、工作區和閱讀庫保留。已有“清除網站數據”入口可清除全部普通網站數據。
- **設置 → 保護選項**：控制鏈接參數清理、本地高風險網址檢查和前台過濾規則更新。自動更新默認關閉；開啓後普通瀏覽進入前台時檢查，成功更新至少間隔 24 小時，失敗至少間隔 1 小時。更新失敗繼續使用舊規則。
- **打開系統 App 設置**：進入 iOS 管理的語言、硬件權限等設置。默認瀏覽器選項取決於安裝資格和系統版本。

關閉導航保護開關不會允許憑據網址或任意腳本協議。系統 WebKit 的保護和權限提示由 iOS 管理。

## 閱讀、批注與翻譯

1. 打開普通網頁，選擇 **更多 → 閱讀與批注 → 讀取當前網頁**。讀取當前頁面正文；登錄和支付表單、輸入值、隱藏文字不進入資料。正文上限為 24,000 個字符，截斷時顯示提示。
2. 在原文中複製一段文字到“引文”，填寫批注，然後點擊 **保存資料與批注**。引文必須在原文中存在；匹配片段高亮顯示。讀取本身只保留在當前界面，主動保存才寫入本機加密庫。
3. 如需翻譯，先在設置中配置模型服務，再點擊 **預覽並翻譯**。檢查服務地址、模型及脫敏後的正文，確認後發送。批注、瀏覽歷史和 PDF 不發送。譯文生成後仍需保存；iPad 寬屏並排顯示，iPhone 上下顯示。
4. 在資料列表搜索標題、來源、正文、批注或譯文。打開資料可歸檔；打開“查看歸檔”可重新打開並取消歸檔。導出為普通文本，包含原文、來源、批注及譯文。
5. 刪除資料需要再次確認，刪除本機記錄後不能撤銷，已導出的文件保留。最多保存 100 條、合計 8 MB；歸檔仍計入容量。

資料使用 AES-GCM 加密，密鑰保存在本機鑰匙串。解密失敗時保留原文件並停止寫入；不同窗口或陳舊編輯界面的保存衝突會被拒絕，需要返回列表重新打開。設備密鑰不會隨普通文件複製，因此不能僅複製密文就當作可跨設備恢復的備份。

私密閱讀不會自動保存正文或來源。保存、導出網站資料時明確說明保留範圍並再次確認；取消翻譯預覽不會發送模型請求。譯文需要人工核對，本輪合成模型服務驗收只驗證請求和交互，不評估真實模型翻譯質量。

### PDF

在閱讀列表點擊 **導入 PDF 頁面**，從“文件”選擇 PDF，輸入從 1 開始的頁碼並讀取。只提取該頁已有文字層；文件不超過 20 MB、頁數不超過 1,000 頁。無文字層的掃描頁、加密文件或無效頁碼會給出錯誤。本輪沒有 OCR，PDF 正文只在本機讀取、保存和導出。

## 瀏覽器操作

打開 **更多 → AI 助手 → 瀏覽器操作與工作流**，選擇本窗口、當前模式中的標籤。

- 可直接選擇分組、保存工作區、打開自己輸入的網址、重載、關閉或向下滾動當前頁。填好名稱或網址，點擊 **預覽操作**，核對範圍後確認執行。
- 也可填寫目標，讓模型建議步驟。第一次確認只發送目標、脫敏標題和網址；模型返回的步驟必須通過校驗，第二次確認才執行。
- 一個計劃最多 6 步、16 個選定標籤及 16 個輸入網址，5 分鐘後過期，同一計劃不能重復執行。窗口、模式、頁面來源或導航版本變化後，需要重新預覽。
- 關閉或重載只能放在最後一步；模型不能增加用戶未輸入的網址、運行任意腳本、填表、登錄或付款。取消保留已完成步驟，界面報告完成數量，不承諾整體撤銷。

私密網址保存為普通工作區時，確認區會明確說明關閉私密標籤後仍保留。

## 前台網頁變化檢查

在瀏覽器操作中打開 **檢查當前網頁更新**。選擇 1、5 或 15 分鐘，確認後讀取當前正文，後續重新載入並比較正文摘要。顯示檢查次數、時間和是否變化；不保存正文，不發送模型。離開面板、切換模式或進入後台即停止，不提供關閉 App 後的定時保證。重新載入網頁可能影響頁面臨時狀態，應使用普通信息頁面。

## 下載網絡與容量

打開 **更多 → 下載 → 下載設置與存儲**。可控制蜂窩網絡、按流量計費網絡和低數據模式，選擇單文件 100 MB、500 MB、1 GB 或 5 GB 上限。新任務保存創建時的規則；暫停續傳、鏡像切換及重新打開 App 後，舊任務繼續使用原規則。系統可以延後後台傳輸，強制退出 App 後需要重新打開並核對狀態。

HTTP 下載、Metalink、鏡像切換和哈希校驗繼續可用。BT/磁力下載需要 iOS 專用後端與後台方案，本輪沒有移植；也未加入任意第三方擴展安裝、跨設備賬號同步，以及依賴 Chromium/V8 的深層保護模塊。各端源碼與驗收狀態以[四端清單](platform-features.zh-TW.md)為準。
