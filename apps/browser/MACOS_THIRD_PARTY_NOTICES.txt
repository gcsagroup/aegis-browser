puff.c
Copyright (C) 2002, 2003 Mark Adler
For conditions of distribution and use, see copyright notice in puff.h
version 1.7, 3 Mar 2003

puff.c is a simple inflate written to be an unambiguous way to specify the
deflate format.  It is not written for speed but rather simplicity.  As a
side benefit, this code might actually be useful when small code is more
important than speed, such as bootstrap applications.  For typical deflate
data, zlib's inflate() is about four times as fast as puff().  zlib's
inflate compiles to around 20K on my machine, whereas puff.c compiles to
around 4K on my machine (a PowerPC using GNU cc).  If the faster decode()
function here is used, then puff() is only twice as slow as zlib's
inflate().

All dynamically allocated memory comes from the stack.  The stack required
is less than 2K bytes.  This code is compatible with 16-bit int's and
assumes that long's are at least 32 bits.  puff.c uses the short data type,
assumed to be 16 bits, for arrays in order to conserve memory.  The code
works whether integers are stored big endian or little endian.

In the comments below are "Format notes" that describe the inflate process
and document some of the less obvious aspects of the format.  This source
code is meant to supplement RFC 1951, which formally describes the deflate
format:

   http://www.zlib.org/rfc-deflate.html

Bergamot Translator 0.4.9：MPL 2.0
来源：https://github.com/browsermt/bergamot-translator
npm：https://registry.npmjs.org/@browsermt/bergamot-translator/-/bergamot-translator-0.4.9.tgz

对应许可位于 vendor 目录。没有修改这些包的推理或解压实现。

https://github.com/microsoft/onnxruntime/blob/v1.20.1/ThirdPartyNotices.txt 。

MINIM：使用本机训练的 MLP 权重；仅对提取段落评分，不是完整 AX 树策略。
上游代码：https://github.com/yyyyhx/MINIM/tree/456c60b6fd47941d1e5849db573dbbcb488e3ae7
训练数据：https://huggingface.co/datasets/Chaoyu112358/MINIM-data （数据卡 MIT）。
PhishLang：MobileBERT 的 ONNX INT8 本机版本；46 条已观察试验样本的分类与原权重一致。
上游模型：https://github.com/UTA-SPRLab/phishlang/tree/6b7283854ef8a6edc73f945c1ce7e51b2e1dc4fd
上述研究代码/模型未发现完整明确的许可，本包只用于用户要求的本机实验，尚不能作为公开分发许可凭据。
