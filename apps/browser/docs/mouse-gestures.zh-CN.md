# 桌面鼠标手势

2026-10-09：整合 Quinn 改动后的 Mac 候选为 Ver 2.2 (144)，Chromium `155.0.8059.40`；Windows 尚待构建与实机验收，正式发行尚未完成。最新范围见[整合记录](../../../docs/audit/main-quinn-integration-2026-10-09.zh-CN.md)，141 的[历史验收](../../../docs/audit/mouse-gestures-acceptance-2026-10-09.zh-CN.md)单独保留。

在设置侧栏打开“鼠标手势”，或访问 `chrome://aegis/gestures.html`。按住右键画出方向，松开执行；右键轻点仍然打开菜单。按 Esc、切换标签或窗口可以取消，按住 Shift 再右键可临时跳过手势。

## 默认动作

| 手势 | 动作 |
| --- | --- |
| ← | 后退 |
| → | 前进 |
| ↑ | 向上滚动 |
| ↓ | 向下滚动 |
| ↑↓ | 刷新 |
| ↓→ | 关闭当前标签 |
| ↓← | 恢复关闭的标签 |
| ↑← | 左侧标签 |
| ↑→ | 右侧标签 |

普通网页、设置页和内置 PDF 阅读器使用同一套普通动作。PDF 上一页、下一页、适合宽度和适合整页可在设置中自行绑定，仅对内置 PDF 阅读器生效。未绑定或方向不明确的笔画不会执行操作。

## 自定义与练习

- 在方向栏输入 `L/R/U/D` 或对应箭头，选择动作，然后保存。最多 8 个方向，同一方向组合不能重复绑定。
- 练习区使用当前表单的配置，只显示识别结果，不执行关闭标签、导航等操作。画出新方向后，“添加手势”会填入这次方向。
- 可以关闭手势、关闭轨迹提示或调整识别距离。距离越大，越不容易被小幅抖动触发。
- 网站排除名单每行填写一个域名，只匹配该完整域名；子域名需要单独添加。设置保存在当前浏览器资料中。

首版不包含超级拖拽、滚轮组合、左右键组合及斜向手势。绘制时离开内容区、丢失按键状态或超过 10 秒会取消，不将未完成的笔画延续到下一次操作。

## PDF 绑定示例

1. 打开鼠标手势设置，添加方向 `LR`，选择“PDF 下一页”，保存设置。
2. 在内置 PDF 阅读器中按住右键，先向左再向右，松开后翻到下一页；已经在最后一页时停留原页。
3. 在普通网页绘制同一方向不会执行 PDF 动作；不再需要时删除该绑定并保存。

识别距离默认为 16 像素，可调范围为 8–64 像素。设置保存后刷新页面，可检查配置是否保留。

## 验证入口与范围

原生输入层在渲染前识别手势，动作绑定到开始绘制时的标签和文档。导航、失焦或文档失效后不执行旧动作；关闭标签等操作延后到当前输入回调结束后执行。网页无法直接调用浏览器动作接口。

- `aegis_gesture_unittests`：小幅抖动、方向组合、斜线拒绝、取消、无效输入、设置原子校验及网站排除。
- `interactive_ui_tests --test-launcher-jobs=1 --gtest_filter='AegisGestureBrowserTest.*:*AegisGesturePdfTest.*'`：使用系统输入状态的串行交互测试：导航、右键菜单、左键点击与拖选、滚动、刷新、标签切换/关闭/恢复、Esc/出界/导航/失焦取消、跨进程子框架、设置保存/拒绝和练习保护；分别覆盖默认 OOPIF 与旧 GuestView PDF 的翻页、边界、适合宽度/整页及普通后退。
- 真实 App 检查：设置入口、布局、配置保存回读、右键菜单与普通页面行为。自动测试通过不能替代 Windows 原生验收。

行为已加入 `release-feature-contract.json` 的 `MouseGestures` 项，适用 Mac ARM64 与 Windows x64。每次上游适配须保留并运行相关回归；当前 Windows 构建与实机验收结果需单独提供，不能借用 Mac 收据。正式发行仍遵守完整平台、签名和更新链路门槛。
